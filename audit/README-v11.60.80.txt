Aviquestionbank v11.60.80 — 고정익 운항기술기준 숫자 규정 객관식

적용 방법
1. ZIP 압축을 풉니다.
2. 안의 index.html, assets, data, references, audit 및 안내 파일을 기존 GitHub 저장소의 같은 위치에 덮어씁니다. 저장소의 다른 파일은 삭제하지 않습니다.
3. GitHub Pages 배포가 끝난 뒤 웹페이지를 새로고침하거나 앱을 완전히 닫았다가 다시 엽니다.
추가 SQL, Python, 설치 프로그램은 필요하지 않습니다. APK를 다시 만들 필요도 없습니다.

들어가는 곳
이론·참고서 → 참고서 홈 → 고정익항공기를 위한 운항기술기준 → 숫자 규정 객관식
문제은행의 교재 선택 화면에서도 ‘고정익 운항기술기준’으로 들어갈 수 있습니다.

추가 내용
국토교통부고시 제2026-154호, 2026년 3월 25일 개정 전문의 제7·8장을 기준으로 숫자 규정 중심의 창작 4지선다 100문항을 추가합니다. 공식 시험문제의 전재가 아닙니다.
- 계기·통신·비상장비: 17문항
- 산소·의료·구명장비: 13문항
- RVSM·PBN·비행기록: 13문항
- 승무원 자격·음주: 15문항
- 연료·교체공항: 18문항
- 일반 비행절차: 14문항
- 항공운송·성능: 10문항

사용 기능
- 전체 영역 또는 영역별 선택
- 전체 / 최근 오답 / 아직 안 푼 문제 선택
- 무작위 10문항 / 20문항 / 선택 범위 전체 출제
- 즉시 채점, 정답 해설, 근거 조항과 공식 전문 PDF 쪽수 표시
- 각 문항에서 근거 PDF 쪽으로 바로 연결
- 기존 계정의 문제별 풀이 기록에 저장. 홈 진도·공부기간 목표·단원별 현황·v79 누적 학습 분석에 연결
- 100문항 중 풀이 가능한 범위만 출제하며 오류 신고 문항은 제외

출제 기준
‘이상/초과/이내/미만’, 운송사업 여부, 엔진 종류, 장착·증명 날짜, 일반 기준과 승인 예외를 문항 조건에서 구분했습니다.
보정연료 5%/3%와 5분 체공 하한을 함께 적용하는 계산 문제를 포함합니다. FDR 일반 25시간 및 특정 대상 예외 30분, CVR 일반 2시간 및 해당 대상 25시간, 2025년 이후 대상 CARS 2시간 등을 구분합니다.
교체비행장 기준의 km 단위는 해당 조항의 표기값을 사용합니다. 서로 다른 기준표나 단위를 임의로 합치지 않았습니다. 제7·8장의 숫자 규정을 선별한 100문항으로, 모든 규정을 빠짐없이 다룬 문제집은 아닙니다.

공식 출처
고정익항공기를 위한 운항기술기준, 국토교통부고시 제2026-154호(2026.3.25.)
국가법령정보센터 공식 전문 PDF: https://www.law.go.kr/LSW/flDownload.do?flSeq=162882605
공식 PDF 사본: references/fsr-aeroplanes-2026-154.pdf (420쪽)
기존 참고서 원문 학습과 출제자별 주관식은 2024년 발췌 자료를 그대로 유지합니다. 새 객관식은 위 2026년 전문을 별도의 기준으로 사용하며 화면에도 버전을 표시합니다.

누적 적용
이 ZIP은 v11.60.79 공개 패치에 이번 기능을 더했습니다. v77 비행이론 검수, v78 기상 기준 화면, v79 마이페이지 누적 학습 분석의 공개 파일을 함께 포함하므로 해당 공개 ZIP을 따로 먼저 적용할 필요는 없습니다.
기존 KYJ 전용 기상 자료의 서버 권한과 데이터, 스터디그룹 주관식, 저장된 학습 기록은 변경하지 않습니다. 기존 전용 기상 자료의 별도 SQL 설정은 그대로 사용하며 이번 운항기술기준 문제 추가에는 새 SQL이 없습니다.

검증
원문 쪽수·조항·숫자 근거를 대조했고, 주요 표와 비행기록·연료·착륙성능 페이지를 렌더링해 확인했습니다.
100문항 전체를 실제 앱 채점 흐름으로 실행하여 정답·해설·출처 링크를 확인했습니다. 정답 위치는 A/B/C/D 각 25문항이며, 연습할 때 문제 순서는 무작위입니다.
오답·미학습 필터, 7개 영역, 기존 기록 저장 호출과 마이페이지 누적 분석 연결, 불완전 데이터 차단 및 재시도, 반복 로드 시 메뉴 중복 방지를 확인했습니다.
320px·390px·1440px 화면에서 화이트/다크 모드, 나눔스퀘어, 가로 넘침을 확인했습니다. 서버 기록 검증에는 가상 응답을 사용했으며 실제 운영 계정의 데이터를 변경하지 않았습니다.
