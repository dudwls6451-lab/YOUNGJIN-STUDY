Aviquestionbank v11.60.83 — 공중항법 전체 문항 학습영역 태그·단계 연결

적용 방법
1. ZIP 압축을 풉니다.
2. 안의 파일과 폴더를 기존 GitHub 저장소의 같은 위치에 덮어씁니다. 다른 기존 파일은 삭제하지 않습니다.
3. GitHub Pages 배포가 끝나면 웹페이지를 새로고침하거나 앱을 완전히 닫은 뒤 다시 엽니다.
Python, 추가 SQL, APK 재빌드는 필요하지 않습니다.

분류 범위
공중항법 전체 879문항 = 예상문제 529 + 모의고사 14회 350문항을 기존 31개 학습영역에 연결했습니다.
기존 이론 과정은 모의고사 350문항을 의도적으로 단계시험에서 제외하고 있었기 때문에 마이페이지에서도 단계 미지정으로 표시되었습니다.
이번 패치는 모의고사를 포함한 전 문항에 대표 학습영역 1개씩 연결합니다. 31개 단계의 문항 수 합계는 중복 없이 879문항입니다.
밀도고도·항적난기류, 항로 절차·도착 절차, 혈류량·항공생리, 트랜스폰더 등 기존 단계 연결의 경계 문항 18개도 내용에 맞게 정리했습니다.

사용 방법
- 마이페이지 → 공중항법 교재 박스 → 단계별: 전체 문항의 단계별 진도·정답률·회독 수, 목표 미달 경고를 확인합니다.
- 각 단계의 이 단계 풀기·오답만 풀기로 해당 영역을 공부합니다.
- 문제 선택 → 과목 공중항법 → 학습영역: 원하는 영역을 선택합니다.
- Study Unit·소단원(모의고사 회차)·전체/오답/미학습 조건과 학습영역을 조합할 수 있습니다.
- 문제 상단에도 학습영역 이름이 표시됩니다.
기존 SU 9 모의고사 및 소단원 9.1~9.14, 각 회차 25문항 구성은 그대로 유지됩니다.

보존되는 항목
문제 ID, 원래 교재·SU·소단원·회차·출처, 문제·보기·정답·해설·그림, 저장된 풀이기록과 학습목표를 보존합니다.
이론 31개 단계의 ID와 설명 본문, 기존 읽음/통과 기록을 유지합니다. 일부 단계 제목만 실제 연결 주제를 더 잘 나타내도록 보완했습니다.
분류 설치는 학습기록을 초기화하거나 과거 풀이를 재채점하지 않습니다.
기존 문항 tags에 학습영역 태그를 추가하고 별도의 topic_id 및 theory_stage_id를 부여합니다. 실행 중에는 검토된 고정 ID 분류표를 사용합니다.
