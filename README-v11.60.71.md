# Aviquestionbank v11.60.71 — 단원별 바로 풀기

**v11.60.70까지 적용한 사이트에 덮어쓰는 추가 패치입니다.** 압축을 풀어 `index.html`과 `assets/` 파일을 같은 경로에 추가·덮어쓰고 배포하세요. 기존 `assets/` 폴더에 병합해야 합니다.

## 사용 방법

마이페이지에서 과목 박스를 눌러 단원별 진도를 열면, 각 Study Unit 아래에 두 버튼이 나옵니다.

- **이 유닛 풀기 (N)**: 해당 유닛에서 현재 출제 가능한 문제 전체를 학습합니다.
- **오답만 풀기 (N)**: 해당 유닛 중 **저장된 공부 기간 안에 한 번이라도 틀린 문제**를 학습합니다. 이후 맞혔어도 그 기간에 오답 이력이 있으면 포함합니다.

단계별 보기에서도 ‘이 단계 풀기’와 ‘오답만 풀기’를 사용할 수 있습니다. 문제 수는 버튼에 표시하며, 해당 문제가 없으면 버튼이 비활성화됩니다. 서버 이력을 불러오는 중에는 오답 풀이 버튼을 비활성화합니다.

오류 신고·미채점 문항은 기존 학습 기준에 맞춰 출제에서 제외합니다. 따라서 진도 집계에 표시된 전체 문항 수와 출제 가능한 문항 수가 다를 수 있습니다. 단계 문항이 일부만 로드된 경우에는 현재 로드된 문제를 대상으로 합니다.

## 학습 연결

- 일반 교재는 선택한 문제 ID만 기존 학습 화면으로 전달합니다. 이전의 즐겨찾기·그림 제외·출제 수 필터 때문에 범위가 바뀌지 않도록 합니다.
- 이스타항공은 기존 회차 학습 화면으로 연결하여 객관식과 단답형을 함께 지원합니다. 단답형은 기존 0~4점 자가채점을 사용합니다.
- 이스타항공의 선택 범위 학습은 기존 전체 회차의 이어풀기 기록과 다른 저장 키를 사용하므로 서로 덮어쓰지 않습니다.
- 답안은 기존 기록 경로로 저장되어 기간별 진도·정답률·회독 및 홈의 학습목표 집계에 반영됩니다. 정상 로그인 상태에서는 기존 서버 풀이 기록 경로도 그대로 사용합니다.
- 일일 퀴즈 잠금과 문제은행 접근 권한을 확인합니다. 해당 과목·단원에 문제가 없으면 다른 범위로 대체 출제하지 않습니다.

## 변경 파일

- `index.html`: 새 버전 본체·학습목표 모듈·이스타항공 모듈·상세 화면 스타일 연결
- `assets/app-v11-60-71.js`: 선택 문제의 검증과 기존 학습 화면 연결
- `assets/study-plan-v11-60-71.js`: 단원·단계의 출제 버튼, 기간 내 오답 집계와 출제 수 표시
- `assets/study-progress-detail-v11-60-71.css`: 버튼 배치와 비활성화 스타일
- `assets/eastar-course-v11-60-71.js`: 객관식·단답형을 포함한 선택 범위 학습

문제와 이론 데이터 파일은 수정하지 않았습니다. 기존 v11.60.70 이스타 5회차 데이터와 그림을 사용합니다. 새로운 SQL이나 목표 재설정은 필요하지 않습니다.

## 검증

Chromium PC 1440px·모바일 390px에서 단원 전체·기간 내 오답·이론 단계 전체·단계 오답 출제 범위를 검사했습니다. 다른 유닛의 오답, 기간 밖의 오답, 오류 신고 및 미채점 문항이 섞이지 않는지 확인했습니다. 이전의 그림 제외·즐겨찾기·출제 수 설정이 있어도 선택한 범위가 정확히 전달되는 것을 확인했습니다.

이스타항공의 객관식 1개와 단답형 1개를 선택해 끝까지 풀고 6/6점 결과와 풀이 기록 갱신을 확인했습니다. 전체 45문항 진입과 기존 회차 이어풀기 기록 보존도 검사했습니다. 일일 퀴즈 잠금·권한 제한·다른 과목 ID로 요청한 빈 범위를 검사했습니다.

기존 기간별 집계·목표 수정·정답률 경고·회독·6개 과정 총 164단계 로딩 검사를 PC 1440px 및 모바일 390·320px의 다크·화이트 모드에서 다시 실행해 통과했습니다. 본체 변경 범위는 신규 학습 연결 함수와 학습목표 초기화 연결뿐이며, 나머지 v11.60.67 본체 내용이 동일한지도 비교했습니다.

실제 본체와 학습목표·이스타항공 모듈을 함께 사용하되, 인증·Supabase·일반 문제 피드는 테스트용입니다. 실제 계정 및 운영 서버 배포 검사는 실행하지 않았습니다. 상세 결과는 두 validation JSON에 포함합니다.
