# Aviquestionbank v11.60.66 — K-AIM 원본 재대조 패치

## 적용 방법
1. ZIP을 풀고, 안의 index.html · assets · data를 기존 GitHub 저장소의 같은 위치에 덮어씁니다. 기존 폴더 전체를 삭제하지 마세요.
2. GitHub Pages 배포 완료 후 페이지를 새로고침합니다. 기존 웹 연결형 앱은 앱을 완전히 종료했다가 다시 실행합니다.
3. 이번 패치용 APK 재설치나 Supabase SQL 실행은 필요 없습니다.

v11.60.64의 화면/동기화 코드 위에 적용하는 변경분입니다. v11.60.65의 CPL 문장 정리 데이터와 함께 사용할 수 있습니다. IR Gleim·학습목표 수정·홈 진도 자동 표시를 위한 기존 스크립트 참조를 유지합니다.

## 수정 범위
- K-AIM 1,122문항이 수록된 원본 218페이지 재OCR 및 문자열 대조.
- 확인된 186문항 교정: 지문 130문항, 보기 128문항, 정답 연결 70문항. 항목별 숫자는 중복됩니다.
- 지문이 보기로 들어가거나 다른 문제가 뒤에 붙은 부분을 원본과 대조해 재구성했습니다.
- K-AIM-1115 · 1116 · 1117 · 1119의 기호 그림 4개를 원본에서 추출했습니다.
- 문제 ID와 교재 분류, 기존 학습·정오답·목표 기록은 유지됩니다. 과거 채점 결과를 소급 변경하지 않습니다.
- v44·v57 교정이 반영된 실제 데이터를 기준으로 변경내역을 계산했습니다. 이 패치 이후 날짜의 관리자 수정본은 우선합니다.

## 원본 문항 자체가 모호한 경우
다음 7문항은 삭제하지 않고 자동 출제와 채점에서 제외했습니다. 일반 학습/시험, 오답/즐겨찾기 복습, K-AIM 이론시험, 오늘의 퀴즈에 적용됩니다.

| 문제 ID | 확인한 문제 |
|---|---|
| K-AIM-423 | 호출방식의 네 보기 중 틀린 것 하나를 확정하기 어려움 |
| K-AIM-457 | Stopway 문제에 틀린 보기 C·D가 함께 존재 |
| K-AIM-867 | CVFP의 A·B가 원본 해설에 함께 부합 |
| K-AIM-963 | B·D가 동일한 수치로 인쇄됨 |
| K-AIM-1036 | 해설의 75 ft에 해당하는 보기가 없음 |
| K-AIM-1071 | 네 보기 모두 원본 해설의 저산소증 증상에 포함 |
| K-AIM-1086 | 비행착각 문제에서 복수의 보기가 성립 |

원본 정답표를 무조건 복사하지 않았습니다. 구조신호 X, QNH 지시고도, 운량 FEW, 넓은 활주로 착각 등 해설과 정답표가 상충하는 경우를 변경내역에 별도 표시했습니다.

## 검증과 한계
실제 Chromium의 PC 1440px/모바일 390px에서 수정 문항 풀이·정답 기록, 그림 4개 로딩, 제외 문항의 각 출제 경로 차단, 관리자 최신 수정 우선, 다른 교재 보존을 확인했습니다. 두 테마의 화면 너비 검사를 통과했습니다. 인증과 원격 데이터 API는 테스트용 대역이며 실제 계정 쓰기와 네이티브 APK 실행은 하지 않았습니다.

218페이지의 재OCR은 전체에 수행했지만, 이미지 수동 대조는 손상 지문·보기·정답 불일치 후보를 우선했습니다. 1,122문항 모두의 수동 전수 검증이나 최신 규정 전수 감수를 보증하는 패치는 아닙니다. 구판 교재의 출제 범위는 유지합니다.
