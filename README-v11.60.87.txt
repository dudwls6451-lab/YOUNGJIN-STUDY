사용 방법
마이페이지 → 공부 기간과 목표 → 목표 수정에서 교재별 목표 회독 수(1~10), 마지막 회독 진도율, 목표 정답률을 설정합니다. 회독 수가 없던 기존 목표는 자동으로 1회독으로 읽으며 기존 진도율 목표를 유지합니다.

100문항·3회독·마지막 진도 100% = 총 300문항 풀이.
100문항·3회독·마지막 진도 50% = 2회독 완료 + 3회독 50문항, 총 250문항 풀이.
각 회독은 해당 교재의 모든 문항을 한 번씩 풀어야 완료됩니다. 같은 문항의 초과 반복 기록은 다음 회독에서 반영됩니다. 미학습 문항을 반복 문항으로 대체하지 않습니다. 정답 여부와 관계없이 풀이를 회독에 반영하며 정답률 목표는 별도로 표시합니다.

마이페이지 상단 전체 목표 게이지는 목표에 포함한 교재들의 필요 풀이 수를 합산한 비율입니다. 1회독은 연한 파랑, 2회독은 중간 파랑, 3회독 이상은 진한 파랑으로 구분합니다. 교재 목표 게이지와 홈에도 동일한 계산을 적용하며 유닛/단계의 회독 게이지에도 같은 색상을 적용합니다. 유닛 정답률 미달 경고와 해당 유닛/오답 풀이 버튼은 유지합니다.

홈 일일 목표도 전체 회독 목표 ÷ 공부 일수(올림)로 계산합니다. 기간의 시작일과 종료일을 모두 포함하고 한국 시간을 사용합니다. 기존 18·20·22·23시 미달성 알림을 그대로 사용합니다. 같은 계정으로 접속하면 회독 목표도 기기 간 동기화됩니다. 구버전 화면이 열린 다른 기기도 새로고침해 주세요.

학습기록은 삭제하거나 초기화하지 않습니다. 선택한 공부 기간에 저장된 날짜별 풀이 이력으로 다시 계산합니다. 서버에 날짜별 이력이 없는 과거 기기 내 기록은 소급 집계하지 않습니다. 불러오지 못한 교재는 합계에서 제외하고 안내를 표시합니다. 문제은행 내용 및 v11.60.86 공중항법 오류 수정은 변경하지 않습니다.
