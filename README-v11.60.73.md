# Aviquestionbank v11.60.73 — 비행정보 및 관제절차 그림·도표 분리 패치

v11.60.71 이상에 압축파일 내부의 파일과 폴더를 저장소 루트에 덮어씁니다. v11.60.72를 대체하는 패치이므로 72번을 먼저 적용할 필요가 없습니다. 이미 72번을 적용했어도 같은 방법으로 적용합니다.

## 변경 내용

- 비행정보 및 관제절차 1,042문항, 7장·30개 소단원 및 이론학습을 포함합니다.
- 전체 문제 페이지를 확인해 실제 그림이 있는 17문항만 문제 그림을 연결했습니다. 단어에 ‘부호’, ‘PAPI’ 등이 있다는 이유만으로 일반 문항에 그림을 붙이지 않습니다.
- 지문에 필요한 그림 11개와 보기 자체의 그림 24개를 개별 영역으로 추출했습니다. 보기 그림은 A~D 선택지 안에 표시되며 보기 순서가 섞여도 해당 선택지와 함께 움직입니다.
- 해설용 그림·표 67개를 별도 영역으로 추출해 해당 공통/개별 해설을 사용하는 210문항에 연결했습니다. 학습모드에서는 답을 고른 뒤, 시험에서는 제출 후 결과 화면에서 표시됩니다.
- 문제·보기 전체 캡처와 문제 페이지 전체를 보여주는 원문 확인 기능을 문제 화면에서 제거했습니다. 이 압축파일에는 전체 문제 캡처 1,044개가 포함되지 않습니다.
- 그림 때문에 OCR 텍스트에 섞였던 문자 조각과 잘린 지문을 원본과 대조해 수정했습니다. 문항 ID와 교재 정답, 단원 분류는 유지합니다.
- 개별 그림 확대, 시험 결과의 도형 보기, 다크/화이트 테마의 새 문제 글자·보기 색상을 보완했습니다.

## 파일 위치

- `assets/aim73/figures/`: 개별 추출한 문제·보기·해설 그림 및 표 102개. 문제/보기 그림은 파일명에 문항 ID가 들어 있습니다.
- `data/figure-index-v11.60.73.csv`: 각 이미지의 연결 문항, 보기, 원본 PDF 쪽수와 인쇄 쪽수 목록입니다.
- `data/flight-info-atc-figures-v11-60-73.json`: 이미지 영역과 용도, 해설 연결 기준을 기록한 목록입니다.
- `assets/aim72/pages/`: 이론학습에서 사용하는 원문 이론 110쪽만 포함합니다. 문제 화면의 이미지로 사용하지 않습니다.
- `data/questions-flight-info-atc-v1.json`: 수정한 1,042문항 데이터입니다.

72번 패치를 이미 올렸다면 서버에 예전 `assets/aim72/questions/` 폴더가 남아 있을 수 있습니다. 이번 코드에서는 사용하지 않으므로 해당 폴더는 삭제해도 됩니다. `assets/aim72/pages/` 전체는 삭제하지 마세요. 이론학습에서 일부 페이지를 계속 사용합니다.

## 적용 및 확인

1. 기존 저장소를 백업하고 압축파일 내부 파일을 루트에 덮어씁니다.
2. GitHub Pages 반영 후 새로고침합니다. 오래 열린 앱은 종료 후 다시 실행합니다.
3. 비행정보 및 관제절차의 PAPI·필수보고지점·공항 표지판·항공도 기호 문항을 확인합니다.

v11.60.71까지 적용되어 있던 다른 패치와 데이터는 그대로 필요합니다. APK 재빌드, 데이터베이스 변경 및 학습기록 초기화는 필요하지 않습니다. 기존 1,042문항의 ID와 정답을 유지해 기존 진도·정답률·목표 기록과 연결됩니다.

## 검증 범위

- 전체 데이터의 ID·정답·단원 분류 유지, 이미지 파일 및 참조, 이론 110쪽과 7단계 연결을 확인했습니다.
- 원본 질문 페이지 216쪽을 시각적으로 검토하고, 개별 추출한 영역에 다른 문제나 하단 정답표가 들어가지 않았는지 확인했습니다.
- 실제 수정 코드와 데이터로 PC/모바일의 문제 풀이, 보기 그림, 확대, 정답 후 해설 그림, 시험 결과 복습 및 기존 교재 이동을 확인했습니다. 인증·서버·다른 문항 피드는 테스트용 응답을 사용했으며 운영 계정이나 배포 서버를 변경하지 않았습니다.
- 정답은 원본 교재 기준입니다. 이번 패치는 그림 분리 및 화면 연결 수정이며 현행 항공 규정에 대한 별도 검증은 아닙니다.
