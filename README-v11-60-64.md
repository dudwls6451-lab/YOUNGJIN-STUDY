# v11.60.64 — 새 교재의 홈 학습 현황 자동 표시

현재 배포된 v11.60.63을 기준으로 만든 변경 파일 패치입니다.

## 적용

ZIP의 index.html과 assets/ 안 파일을 GitHub 저장소 최상위의 같은 경로에 덮어쓰세요. 기존 assets 폴더를 삭제하지 마세요. 배포 후 웹을 새로고침하거나 앱을 종료 후 다시 실행하세요. APK 재설치와 SQL 실행은 필요 없습니다.

## 동작

- 처음 사용하는 계정은 등록된 교재·항공사 과정의 학습 현황이 홈에 기본 표시됩니다.
- 기존 계정은 저장한 집중학습 선택을 유지하면서, 나중에 추가된 교재를 자동 표시합니다. 기존 목록에 없던 IR Gleim도 자동으로 나타납니다.
- 마이페이지에서 항목을 체크 해제한 뒤 ‘선택 저장’을 누르면 숨겨집니다. 저장 당시 화면에 있던 항목 목록도 함께 기록해, 숨긴 항목과 새 항목을 구분합니다.
- 이 목록을 기존 계정 동기화 데이터에 함께 보관하므로 다른 기기에서도 같은 구분을 사용합니다.
- 예전 버전은 항목 목록을 기록하지 않았기 때문에, 최초 전환 시 IR 추가 전의 8개 교재와 3개 항공사 과정을 기존 목록으로 간주합니다. 기존에 직접 IR을 선택했던 경우에도 선택 상태를 유지합니다. 이후에는 저장된 목록으로 판단합니다.
- 선택을 편집하는 동안 늦게 불러온 교재가 의도치 않게 숨겨지지 않도록 했습니다.
- 학습목표의 대상 교재·기간·목표 수치와 풀이 기록은 변경하지 않습니다. 홈 표시 선택과 학습목표 대상 선택은 각각 유지됩니다.

## 검증

1440px PC / 390px 모바일 Chromium에서 새 계정 기본 표시, 기존 계정의 IR 자동 추가, 기존 제외 항목 유지, 향후 새 교재 추가, 직접 숨김 후 재접속, 편집 중 늦게 도착한 교재, 다크/화이트 테마와 가로 넘침 검사를 통과했습니다.

격리된 두 브라우저 환경과 공용 테스트 계정 데이터로 표시 목록·항목 목록 동기화, 전체 해제 동기화, 목표 저장 시 표시 목록 보존, 반복 동기화 시 불필요한 쓰기 방지를 검증했습니다. 문제 데이터와 계정 서비스는 테스트 대역을 사용했으며 실제 사용자 계정이나 Android 기기에 쓰기 작업을 하지는 않았습니다.
