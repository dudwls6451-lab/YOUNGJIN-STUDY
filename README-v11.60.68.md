# Aviquestionbank v11.60.68 — 마이페이지 단원별 진도

## 적용

**v11.60.67까지 적용된 사이트용 추가 패치입니다.** ZIP을 풀고 `index.html`과 `assets/`의 두 파일을 저장소의 같은 위치에 덮어쓰거나 추가한 뒤 GitHub Pages 배포를 완료하세요. 화면이 갱신되지 않으면 페이지를 새로고침하세요.

## 사용 방법

1. 마이페이지에서 공부 기간과 목표를 저장합니다.
2. 과목별 목표 박스 또는 ‘단원별 진도 보기’를 누릅니다.
3. Study Unit별 진도율, 푼 문제 수, 정답률과 정답·오답 횟수를 확인합니다.
4. 항공기상·검댕이 항공법규·항공교통통신·K-AIM·비행이론·공중항법은 ‘단계별’ 보기로도 확인할 수 있습니다.

목표를 수정하는 중에도 각 박스 하단의 버튼으로 상세 진도를 확인할 수 있습니다. 저장된 공부 기간이 집계 기준입니다.

## 집계 기준

- 시작일과 종료일을 모두 포함한 한국 시간 기준입니다.
- 진도율은 기간 중 한 번 이상 푼 고유 문제 수 / 현재 로드된 전체 문제 수입니다.
- 정답률은 반복 풀이를 포함한 정답 횟수 / 전체 풀이 횟수입니다.
- 서버 기록과 기기 기록에서 같은 문제·같은 시각의 풀이는 한 번만 셉니다.
- 단계별 현황은 해당 단계에 연결된 문제의 풀이 진도입니다. 이론 읽음이나 단계 시험 통과 현황과는 별도입니다.
- 여러 단계에 속한 문제는 각 단계에 나타나며, 과목 합계에는 한 번만 포함됩니다.
- 연결된 단계가 없는 문제는 ‘단계 미지정 문항’에 표시합니다. 단원이 없는 문제는 ‘단원 미지정’에 표시합니다.
- 단원 정보 없이 회차 정보만 있는 과정은 회차별로 표시합니다.
- 서버 이력 조회 실패, 단계 목록 로딩 실패, 미로드 문제는 화면에서 안내합니다. 단계 목록은 다시 시도할 수 있습니다.

## 변경 파일

- `index.html`: 새 학습목표 모듈과 상세 화면 스타일 연결
- `assets/study-plan-v11-60-68.js`: 과목 박스 클릭, 상세 화면, 단원·단계별 집계
- `assets/study-progress-detail-v11-60-68.css`: 모바일·PC, 다크·화이트 테마, 키보드 포커스와 모션 감소 설정 대응

문제 데이터, 이론 본문, 기존 v11.60.67 본체와 계정 동기화 모듈은 그대로 사용합니다. 저장된 목표·풀이 기록의 키와 형식도 유지합니다. 별도의 SQL 적용은 필요하지 않습니다.

## 검증

Chromium에서 1440·390·320px의 다크·화이트 모드를 검사했습니다. 실제 v11.60.67의 6개 과정 데이터에 있는 164단계를 모두 열어 확인했습니다.

기간 경계, 반복 풀이와 서버·기기 중복 제거, 숫자 순 단원 정렬, 미학습 단원, 서버 오류 안내, 단계 목록 재시도, 열린 화면의 기간·문항 갱신, 목표 수정·저장, 키보드 열기·닫기, 계정 변경 시 상세 화면 닫기를 검증했습니다.

v11.60.67 본체와 v11.60.64 설정 동기화 모듈을 함께 로드하는 별도 검사에서도 마이페이지 진입·목표 수정·상세 진도를 확인했습니다. 인증·Supabase 응답과 일부 문제 데이터는 테스트용이며, 관계없는 부가 모듈은 생략했습니다. 실제 계정이나 운영 서버에 배포하여 실행한 검사는 아닙니다. 상세 결과는 `validation-v11-60-68.json`에 포함했습니다.
