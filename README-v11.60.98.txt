Aviquestionbank v11.60.98 — 고정익 Marshaller Sign · 비상 신호 포함

적용
v11.60.97까지 적용된 기존 사이트 루트에 같은 경로로 덮어씁니다.
변경 파일만 포함한 패치이며 전체 사이트가 아닙니다.
기존 v97 도해 28개를 계속 사용하므로 v97 적용이 필요합니다.
배포 후 새로고침하고, 이전 화면이 남으면 강력 새로고침합니다.
DB/SQL 변경이나 APK 재빌드는 필요하지 않습니다.

이용 경로
참고서 → Marshaller Sign 학습지
학습 모드 선택 → 참고서 학습 → Marshaller Sign 학습지

변경 내용
- 헬기 전용 Hover, Move upwards, Move downwards, Move horizontally left/right,
  Land의 6도해·12문항을 활성 문제·보기·정리표에서 제외했습니다.
- 고정익 적용 지상 유도·정비 28도해를 모두 유지했습니다.
- ARFF 비상 도해 4개와 8문항을 추가했습니다.
  Recommend evacuation: 대피 권고
  Recommended stop: 진행 중 대피·항공기 이동·기타 활동 중지 권고
  Emergency contained: 외부 위험 징후 없음·위험 해소 평가
  Fire: 화재와 발화 위치 알림
- 조종사→유도요원 답신 5종·10문항을 추가했습니다.
  Brakes engaged / Brakes released / Insert chocks / Remove chocks /
  Ready to start engine(s)
  이 5종은 첨부 원문에 그림이 없으므로 동작 설명으로 학습합니다.

원문과 범위
TalkFile_JEPPESEN AIRWAY MANUAL (251113).pdf
ICAO Rules of the Air · Annex 2
5.1.1.1–5.1.1.28 중 고정익 적용 도해: 본문·도해 p.1134–1145
  헬기 전용 5.1.1.16–5.1.1.20의 6도해 제외
5.2.1–5.2.3 조종사 답신: 본문 p.1146, 원문 도해 없음
6.1–6.4 ARFF 비상 신호: 본문 p.1146–1148, 도해 p.1147–1148
첨부본의 해당 수신호 절 전체를 대조하여 고정익 적용 그림 32개를 반영했습니다.
다른 판본이나 국가별 절차까지 모두 망라한다는 의미는 아닙니다.
원문 그림을 직접 발췌했으며 새 그림 생성·좌우 반전은 하지 않았습니다.
32개 그림의 화살표와 동작 단계를 보존하고 한국어 동작 설명·해설을 붙였습니다.
각 문항에 원문 항목번호와 본문·그림 쪽을 기록했습니다.

분야별 항목 / 문항
이동·선회·정지: 14도해 / 28문항
브레이크·초크: 4도해 / 8문항
엔진: 3도해 / 6문항
승인·정비·통신: 7도해 / 14문항
ARFF 비상 신호: 4도해 / 8문항
조종사 답신: 5종, 원문 도해 없음 / 10문항
합계: 32도해 + 설명형 답신 5종 = 37항목 / 74문항

출제 유형
1. 그림·동작 → 의미: 32문항
2. 의미 → 그림·동작: 32문항
3. 답신 동작 → 의미: 5문항
4. 답신 의미 → 동작: 5문항
각 문항은 4지선다입니다. 그림 보기에는 중립적인 대체텍스트를 사용합니다.
한 번의 혼합 풀이는 같은 수신호를 중복 출제하지 않으며 최대 37문항입니다.
74문항을 모두 풀려면 각 유형을 선택하여 각각 '선택 범위 전체'로 풀이합니다.
분야·유형·미풀이·오답·즐겨찾기 필터, 학습·시험 모드, 정리표 검색·확대를 지원합니다.
필수 그림이 모두 로드되기 전에는 답 선택을 차단하며 실패 시 다시 불러올 수 있습니다.
원문 도해가 없는 답신 문제는 그림을 기다리지 않고 풀이할 수 있습니다.

신호 해석
각 문항에 지상 유도요원, 조종사, ARFF 중 누가 누구에게 보내는지 표시합니다.
좌·우 선회는 조종사 관점이며 후진 선회는 꼬리의 좌현·우현 방향을 묻습니다.
유도요원의 오른팔·왼팔은 유도요원 본인의 신체 기준입니다.
ARFF 비상 신호의 대피·중지는 권고입니다. 통상 정지 신호나 관제 허가와 구분합니다.
Emergency contained는 외부 상황에 대한 평가이며 자동적인 이동 재개 허가가 아닙니다.
ARFF 신호는 조종실에 대해 항공기 좌측 전방에서 보내며, 객실에 대해서는 다른 위치도 가능합니다.

기존 데이터
같은 과목의 활성 목록을 v98 목록으로 교체하여 이전 헬기 문항이 남지 않게 했습니다.
유지된 56문항은 기존 ID와 정답 키를 유지합니다.
헬기 문항의 과거 학습 기록은 삭제하지 않으며 활성 출제에서는 제외합니다.
기존 문제은행·세화 태그·OCR 오류 수정·항공약어·벌칙 학습지는 변경하지 않습니다.
이전 헬기 그림 파일은 더 이상 참조하지 않으므로 수동 삭제할 필요가 없습니다.
