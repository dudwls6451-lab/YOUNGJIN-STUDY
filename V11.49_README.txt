- auth-v11-9.js의 canAccessResourceLibrary()가 Supabase 사용자는 항상 false를 반환하도록 되어 있어,

- pending/rejected 계정은 기존처럼 접근 불가

- index.html 덮어쓰기
- assets/auth-v11-10.js 업로드
