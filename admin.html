문제 풀기

1. 자료실 PDF 등록

PDF를 선택하면 브라우저에서 페이지 이미지로 변환하고, 배포용 패치 ZIP을 만듭니다. 원본 PDF는 패치에 포함되지 않습니다.

정적 GitHub Pages 방식
PDF 선택 → 이미지 변환 → 패치 ZIP 생성 → 저장소 루트에 압축 해제/덮어쓰기 → Commit/Push 순서입니다.

변환 라이브러리는 인터넷에서 불러오므로 관리자 페이지에서 PDF 변환 시 네트워크 연결이 필요합니다.

2. JSON 업로드

기존 data/questions.json을 자동으로 읽은 뒤, 업로드한 JSON의 questions 배열을 합칩니다.

3. 병합 결과

GitHub 반영 방법
다운로드한 파일을 저장소의 data/questions.json에 덮어쓴 뒤 Commit 하면 됩니다.

Figure 이미지 연결

문제 JSON에 아래 둘 중 하나를 넣으면 문제 화면에 이미지를 표시합니다.

"image": "figures/FIGURE_229.png"

또는

"figure_refs": ["229"]

figure_refs만 있는 경우 figures/FIGURE_229.png 경로를 자동으로 시도합니다.
