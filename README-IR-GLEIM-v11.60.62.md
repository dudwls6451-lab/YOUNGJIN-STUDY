# IR Gleim 2025 SU 1–10 추가 전용 핫픽스

기준: v11.60.61 문제은행. 기존 앱 본체·공통 스타일·기존 문제 JSON·index.html 전체를 이 압축에 넣지 않았습니다. 원본 PDF, 번역 모델, APK도 포함하지 않았습니다.

## 설치

1. 이 압축의 assets와 data를 GitHub 저장소의 같은 경로에 추가합니다.
2. 기존 index.html의 마지막 `</body>` 바로 위에 다음 **한 줄만** 추가합니다.

```html
<script src="./assets/ir-gleim-addon-v11-60-62.js?v=11.60.62"></script>
```

Python이 설치된 로컬 저장소에서는 대신 `python install-ir-gleim-hotfix.py`를 실행할 수 있습니다. 이 스크립트는 기존 index.html을 백업한 뒤 위 한 줄만 추가합니다. 반복 실행해도 태그를 중복 삽입하지 않습니다. 변경한 index.html도 함께 GitHub에 올리세요.

3. 배포 후 새로고침하면 교재 학습 홈과 교재 문제 풀이에 IR Gleim이 표시됩니다. 기존 APK도 웹을 다시 열면 반영됩니다. APK 재설치는 필요하지 않습니다.

새 파일을 저장소에 올리기만 하고 2번 연결을 생략하면 기존 페이지에서 IR 추가 스크립트가 실행되지 않습니다.

## 번역 범위와 한계

한국어는 로컬 NLLB 모델을 이용한 **자동 번역**이며 항공 용어 보정과 표본 검토를 적용했습니다. 22개 표본 해설은 직접 읽고 다듬었습니다. 960개 전체를 전문 번역으로 전수 검수한 결과는 아닙니다.

영문 해설은 모든 문항의 explanation_en에 보존하며, 일반 학습의 정답 피드백에서 「영문 해설 원문 보기」로 펼쳐 볼 수 있습니다. 용어·수치 자동 대조에서 표시된 91문항은 「번역 대조 권장」으로 표시하고 translation-review-v11-60-62.json에 모았습니다. 그 외 문항이 모두 사람의 검수를 거쳤다는 뜻은 아닙니다. 자동 번역의 표현이 어색하거나 의미가 불분명하면 영문 원문과 대조하세요.

정답은 번역 모델이 추측한 답이 아니라 PDF의 정답/최선답 표기를 사용했습니다. PDF 텍스트의 정답과 원본 이미지에서 별도로 OCR한 정답이 960/960 일치했습니다. 책에 실린 규정·용어를 현재 기준으로 임의 변경하지 않았습니다.
