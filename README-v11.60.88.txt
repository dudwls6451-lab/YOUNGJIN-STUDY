Aviquestionbank v11.60.88 — 홈 오늘 푼 문제 수

적용 방법
압축을 풀고 index.html과 assets 폴더를 기존 GitHub 저장소 루트에 경로 그대로 덮어쓰세요. ZIP 자체를 올리는 방식이 아닙니다. 기존 파일을 삭제할 필요가 없습니다. v11.60.86 또는 v11.60.87이 적용된 저장소 기준이며, 앞선 회독 목표 기능도 함께 포함되어 있어 v87을 따로 먼저 적용할 필요가 없습니다. 추가 SQL, Python 설치, APK 재빌드는 필요 없습니다. 배포 후 웹페이지/앱을 새로 열어 주세요.

변경 사항
홈 집중학습 현황 맨 위에 ‘오늘 푼 문제’를 큰 숫자로 표시합니다. 반복 풀이를 포함한 실제 채점 완료 횟수이며, 고유 문항 수와 정답·오답 횟수를 함께 표시합니다. 공부기간·목표 교재·홈 집중학습 교재 선택과 무관하게 모든 교재의 오늘 풀이를 포함합니다. 시험은 채점되어 기록된 풀이 기준입니다.

집계 기준
한국 시간 오늘 00:00 이상부터 다음 날 00:00 미만까지의 날짜별 풀이 이력을 사용합니다. 오늘의 같은 문항을 두 번 풀면 총 풀이 2문제, 고유 문항 1개로 표시합니다. 같은 계정의 서버 기록과 현재 기기 기록이 겹치면 한 번만 집계합니다. 날짜가 바뀌면 새 날짜로 자동 집계하며 원래 기록은 삭제하지 않습니다.

기기 간 반영
이 기기에서 채점한 답은 즉시 숫자에 반영됩니다. 다른 기기의 기록은 서버 확인 시 합쳐집니다. 페이지 활성 상태에서 주기적으로 확인하고 다시 접속하거나 화면으로 돌아올 때도 확인합니다. 새로고침 버튼으로 바로 확인할 수 있습니다. 서버를 확인하지 못한 경우 안내와 함께 현재 확인된 기록을 표시합니다. 날짜별 이력이 없는 과거 기록은 소급 계산하지 않습니다.

이전 기능 유지
교재별 1~10회독 목표, 전체 목표 달성률, 회독별 게이지 색상, 목표 수정·취소·기기 간 동기화, 회독 기준 일일 목표, 유닛 진도/정답률/오답 풀이, v86 공중항법 문제 수정은 유지합니다. 홈의 실제 오늘 풀이 수와 일일 목표에 반영되는 풀이 수는 초과 반복·목표 교재 등 집계 기준에 따라 다를 수 있습니다.

검증
한국 시간 날짜 경계, 반복/고유 문항 집계, 기기/서버 중복 제거, 1,000건 이상 페이지 조회, 서버 실패, 계정 변경 중 응답, 자정 전환 검증 통과.
모바일/PC 및 화이트/다크 모드 표시, 목표 미설정/기간 밖 집계, 채점 후 실시간 증가, 계정별 분리 검증 통과.
