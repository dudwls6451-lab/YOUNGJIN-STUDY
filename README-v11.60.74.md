# Aviquestionbank v11.60.74 — 검댕이 항공법규 모의고사

이 패치는 **v11.60.73 적용본에 덮어쓰는 추가 패치**입니다. 전체 사이트나 APK 파일은 포함하지 않습니다.

## 적용

1. ZIP을 풉니다.
2. `index.html`, `assets`, `data`를 기존 GitHub 저장소의 같은 위치에 덮어씁니다. 기존 폴더 전체를 삭제하지 마세요.
3. GitHub Pages 배포가 끝나면 페이지를 새로고침합니다.

## 사용

문제은행 → 교재 학습 → 문제 풀이 → **검댕이 항공법규**에서 새 모의고사 영역을 확인합니다.

- 제1회~제28회, 각 25문항, 총 700문항을 회차별로 선택합니다.
- **학습**: 즉시 채점과 해설을 확인합니다.
- **시험**: 마지막에 일괄 채점하고 문제·보기·해설을 다시 확인합니다.
- 회차 버튼은 교재의 문제·보기 순서로 출제합니다. 기존 오류 신고·시험 제외 설정은 계속 적용됩니다.
- 회차별 진도와 정답률은 공부 기간을 설정한 경우 해당 기간 기준, 미설정 시 누적 기록 기준입니다.
- 일반 문제 필터에서도 `Study Unit → 모의고사`, `소단원 → 제N회`를 선택할 수 있습니다.
- 홈·마이페이지·학습목표 계산에 새 문항이 포함됩니다. 마이페이지의 모의고사 유닛에서도 전체·오답 학습을 사용할 수 있습니다.

## 내용과 기록 유지

첨부된 `항공법규_OCR.pdf`의 제3부 모의고사(PDF 227~329쪽)를 바탕으로 구성했습니다. 문제와 정답은 해당 교재 기준입니다. 원문 해설의 법령·교재 참조를 수록했으며, 원문에 별도 해설이 없는 5문항은 그 사실을 표시했습니다.

기존 예상문제 503문항은 변경하지 않았습니다. 기존 제28회 25문항의 ID와 본문·보기·정답을 유지하여 학습 기록을 이어갑니다. 교재 내 모의고사는 총 700문항이며, 기존 예상문제와 합하면 1,203문항입니다.

기존에 제28회만 나중에 추가하던 스크립트 연결을 제거하고, 전체 모의고사를 문제은행 초기 로딩 과정에서 병합합니다. 이로써 과목·진도 목록이 생성된 뒤 뒤늦게 문항이 추가되던 문제를 해결했습니다.

문제 전체나 페이지를 캡처한 이미지는 포함하지 않습니다. 기존 v11.60.73의 비행정보 및 관제절차 그림·도표 연결은 유지됩니다.
