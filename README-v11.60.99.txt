Aviquestionbank v11.60.99 — 홈 풀이 수·날짜별 기록 집계 보완

적용
v11.60.98까지 적용된 기존 사이트 루트에 같은 경로로 덮어씁니다.
전체 사이트가 아니라 변경 파일 5개만 포함한 패치입니다.
index.html과 assets의 세 JS 파일을 모두 올린 뒤 강력 새로고침합니다.
SQL/DB 변경이나 APK 재빌드는 필요하지 않습니다.

확인한 문제
종전에는 날짜별 풀이 이력 저장과 '오늘 푼 문제' 초기화가 공부 기간 통계 모듈에
의존했습니다. 그 파일이 누락되거나 로드되지 않은 조건에서는 정답·오답 누적
카운터는 증가해도 날짜별 이력이 추가되지 않고 오늘 집계는 0에 머물렀습니다.
이 조건을 DOM 실행 환경에서 재현했습니다.
실제 배포 사이트나 사용자의 DB에 접속한 진단은 아니므로, 사용자가 겪은 증상의
원인이 이 조건과 일치한다고 확정한 것은 아닙니다.

수정 내용
- 날짜별 풀이 이력 저장을 채점 본체로 옮겼습니다.
- 오늘 집계의 계정 초기화·화면 갱신을 기간 통계 화면에서 분리했습니다.
- 기간 통계 모듈이 없어도 날짜별 기록 저장과 오늘 집계가 작동합니다.
- 기간 통계가 정상일 때 이력을 두 번 기록하지 않습니다.
- 서버와 이 기기의 같은 풀이 이력은 기존 방식으로 중복 제거합니다.
- 한국 시간 날짜를 연·월·일 요소로 조합하여 브라우저의 날짜 표시 순서에
  따라 자정 경계나 공부 기간 계산이 잘못되지 않도록 했습니다.
- 새 참고서가 비동기로 로드된 뒤에도 홈 현황을 다시 표시합니다.
- 이 기기에 날짜별 이력을 저장하지 못하면 오늘 기록 영역에 실패를 표시합니다.
- 기간 통계 모듈이 없는 상태에서는 초기화되지 않은 설정 동기화 호출을 건너뜁니다.

집계 기준
- 오늘 푼 문제: 모든 교재의 당일 채점된 풀이, 반복 풀이 포함, 한국 시간 자정 기준
- 고유 문항: 당일 풀어 본 서로 다른 문제 수
- 교재 진도: 공부 기간을 설정했다면 해당 기간 안의 기록만 집계
- 공부 기간이 종료되면 오늘 푼 문제는 계속 증가하지만 해당 기간 진도는 증가하지 않음
- 학습 모드: 답을 선택해 채점하면 기록
- 시험 모드: 시험을 제출하여 채점할 때 기록
- 같은 문제를 반복해도 고유 문항 수나 1회독 진도는 이미 학습한 문제만큼 다시 늘지 않음

기존 데이터
문항 ID·문제 데이터·오답·즐겨찾기·학습목표·공부 기간을 변경하거나 초기화하지 않습니다.
기존의 날짜별 로컬 이력 키와 계정 구분을 그대로 사용합니다.
서버의 날짜별 기록은 기존 조회 경로를 통해 집계합니다.
날짜별 이력이 애초에 기록되지 않은 과거 풀이 횟수를 추정하여 생성하지 않습니다.
이 패치는 서버 권한 오류나 DB 장애를 수정하는 SQL 패치가 아닙니다.

검증
JS 세 파일의 구문 검사 통과.
DOM 기능 검사 13개 항목 통과:
1. 기존 교재·약어·벌칙·마샬러의 풀이가 누적 기록·오늘 집계·홈 진도에 즉시 반영
2. 새로고침 뒤 누적 기록과 날짜별 풀이 수 유지
3. 시험 제출 시 한 번만 날짜별 이력 추가
4. 반복 풀이의 총 풀이 수 증가와 고유 문항 수 유지
5. 기간 통계 파일 누락 시에도 계정 초기화·저장·오늘 집계 작동
6. 날짜 표시 순서 변경 환경의 한국 시간 날짜·기간 진도·반복 회독 반영
7. 기존 공부 기간과 목표 보존
8. 한국 시간 자정 경계와 계정별 이력 분리
9. 기간 종료 후 오늘 집계 증가와 기간 필터 유지
10. 모의 서버 저장 및 서버/로컬 이력 중복 제거
11. 모의 서버 로그인 상태의 재접속 시 누적·오늘 기록 유지
12. 저장 공간 오류 표시 및 정상 채점 유지
13. 고정익 마샬러 74문항·헬기 제외·약어 400문항·벌칙 200문항·기존 OCR 수정 유지

검증은 jsdom과 모의 서버를 사용했습니다.
실제 배포 사이트·사용자 DB·실제 브라우저 화면 배치는 검증하지 않았습니다.
