# Aviquestionbank v11.60.70 — 이스타항공 5회차

## 적용 방법

**v11.60.69까지 적용한 사이트에 덮어쓰는 추가 패치입니다.** ZIP의 `index.html`과 `assets/` 내용을 저장소의 같은 위치에 추가·덮어쓴 뒤 GitHub Pages 배포를 완료하세요. `assets/` 폴더 전체를 삭제하거나 교체하지 말고 파일을 병합하세요.

이스타항공 대비 과정에서 ‘5회차’를 선택하면 됩니다. 기존 회차 선택 모듈은 데이터에서 회차를 자동으로 읽으므로 그대로 사용합니다.

## 추가 내용

- 객관식 40문항(각 2점), 단답형 5문항(각 4점): 45문항, 총 100점
- 첨부 문서의 문제·보기·명시 정답·모범답안·해설 반영
- 13·14·37·43·44번 PNG를 같은 번호의 문제에 연결
- 그림은 학습·실전 문제 화면과 결과 화면에서 표시되며 원본 크기로 열 수 있음
- 기존 단답형 0~4점 자가채점 유지
- 기존 마이페이지의 Study Unit 5 진도·정답률·목표 미달 경고·회독 집계에 자동 포함

기존 1~4회차 180문항은 데이터 객체 전체가 동일한지 비교했습니다. 새 데이터 묶음에는 기존 180문항과 신규 45문항, 총 225문항이 들어 있습니다. 기존 문제 ID와 그림 경로는 유지합니다.

## 검증 범위

45개 문제 문장·명시 정답·모범답안·전체 해설을 원문과 비교하고, 225개 고유 ID와 100점 배점을 검사했습니다. 기존 180문항의 동일성과 그림 파일의 SHA-256도 검사했습니다.

Chromium에서 실제 기존 v11.60.67 본체, v11.60.69 학습목표 모듈, v11.60.51 이스타항공 회차 화면을 함께 로드했습니다. PC 1440px 실전, 모바일 390px 실전·학습에서 각 45문항을 끝까지 풀고 객관식 정답 및 단답형 자가채점을 거쳐 100/100점을 확인했습니다. 다섯 그림의 문제·결과 화면 로딩, 풀이 기록 45개 저장, 마이페이지 SU5 및 1회독 집계, 다크·화이트 모드와 가로 넘침 여부를 확인했습니다.

인증·Supabase 및 일반 문제 피드는 테스트용이며 관련 없는 부가 모듈은 생략했습니다. 실제 계정이나 운영 서버 배포 검사는 실행하지 않았습니다. 정답·해설은 제공 자료를 보존한 것으로, 공식 출처를 통한 독립 정답 재검증은 이 패치의 범위에 포함하지 않습니다. 자세한 결과는 두 validation JSON에 포함합니다.
