항공 문제은행 v11.45 패치

적용 순서
1) Supabase SQL Editor에서 supabase/V11.45_STUDY_TIME.sql 전체 실행
2) Success 확인
3) GitHub에 index.html, assets/app-v11-24.js, assets/style-v11-45.css 덮어쓰기
4) GitHub Pages 배포 후 Ctrl+F5

변경 사항
- 홈의 "TOGA STUDY" 문구 제거
- iPad/PC 좌측 메뉴 접기/펼치기 지원
- 빠른 이동: 홈 / 학습 선택 / 각 교재 / 오답 복습 / 마이페이지 / 오류 목록 / 자료실(허용 계정) / 관리자 메뉴
- 접힌 메뉴는 아이콘 중심 78px rail로 축소
- 문제 풀이 화면이 활성화된 동안 실제 활성 시간을 측정
- 탭/앱이 백그라운드이면 학습시간 일시정지
- 10분 동안 아무 입력이 없으면 자동 일시정지, 다시 터치/키 입력 시 재개
- 약 15초마다 Supabase에 누적 저장
- 홈에 "오늘은 X시간 X분 공부했습니다." / "지금까지 X시간 X분 공부했습니다." 표시
- 사용자별/일자별 시간은 user_study_time_daily에 저장
- 관리자는 RLS를 통해 전체 사용자의 학습시간 행을 조회 가능

주의
- v11.45 SQL을 실행하지 않으면 학습시간 저장/조회만 실패하고 기존 문제풀이 기록 기능은 영향을 받지 않습니다.
- 기존 v11.39/v11.41 SQL은 그대로 유지합니다.
