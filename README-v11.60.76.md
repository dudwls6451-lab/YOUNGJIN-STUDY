# Aviquestionbank v11.60.76 통합 업로드 패치

74의 항공법규 모의고사 파일, 75의 기상도 심볼 퀴즈 기능, 76의 KYJ 전용 접근과 스터디 그룹 퀴즈를 한 번에 적용합니다. **74·75 패치를 따로 받을 필요 없습니다.** 현재 사용 중인 문제은행 GitHub 저장소에 덮어쓰는 파일입니다.

## 사이트 적용

1. 이 ZIP을 압축 해제합니다.
2. 압축 안에 있는 **index.html, assets, data, README 파일들을 전부** 기존 저장소의 같은 위치에 올려 덮어씁니다.
3. GitHub Pages 배포 후 새로고침합니다.

`index.html`은 저장소 루트에, `assets`와 `data`는 기존 같은 이름 폴더 안에 합쳐져야 합니다. 압축 파일 이름으로 새 상위 폴더를 만들지 마세요. 기존 저장소나 assets·data 폴더 전체를 지우지 마세요.

Python·PowerShell·BAT 실행은 필요 없습니다. 이 ZIP에는 GitHub에 올리면 안 되는 실제 보호 자료 SQL을 넣지 않았으므로 **압축 내용 전체를 업로드하면 됩니다.**

## 서버 설정 한 번

별도로 받은 **Aviquestionbank-v11.60.76-Supabase-only.sql** 내용을 기존 사이트의 Supabase 프로젝트 SQL Editor에서 실행하세요. **이 SQL 파일은 GitHub에 올리지 마세요.**

앞서 v76의 01_GROUP_QUIZ.sql과 02_PRIVATE_WEATHER_GUIDE.sql을 모두 실행했다면 추가 실행할 필요 없습니다. 이번 SQL은 같은 내용을 하나로 합친 파일이며 재실행해도 기존 문항·풀이·통계를 유지합니다.

GitHub 파일 업로드와 Supabase DB 변경은 별개입니다. 그룹 퀴즈의 공유 저장·채점·권한과 KYJ 전용 자료 제공에 필요한 설정이므로, v76 SQL을 한 번도 적용하지 않았다면 위 SQL을 실행해야 합니다. 브라우저에 관리자 비밀키를 넣거나 사이트 파일에 보호 자료를 공개하지 않습니다.

## 포함 기능

- 항공법규 모의고사: 28회 × 25문항, 총 700문항. 기존 예상문제와 합계 1,203문항.
- 기상 안내서: KYJ 전용 심볼 퀴즈·사전 86문항. 그림·정답은 인증된 서버에서 제공.
- 스터디그룹 게시판 아래 퀴즈: 주관식/객관식 카드 출제, 미리보기, 문제 풀이와 오답 재풀이.
- 그룹원별 누적 출제수·풀이수·정답률. 출제자·출제 시각 표시 및 출제자만 수정.
- 기존 학습 진도, 교재, 목표, 그룹과 게시판은 기존 저장소·DB에서 이어 사용.

## 이전 75를 이미 올렸어도 전체 덮어쓰기

이전 공개 기상 자료 JSON과 그림 경로에는 내용을 비우는 대체 파일이 들어 있습니다. 같은 경로에 함께 덮어써야 보호 자료가 현재 배포본에서 공개되지 않습니다. 새 화면은 이 빈 파일이 아닌 KYJ 인증 API의 원본 그림을 사용합니다. 별도로 파일 삭제 작업을 하지 않아도 되도록 구성했습니다.

예전 Git 이력, 이미 내려받은 파일과 이전 캐시까지 이번 업로드로 회수되는 것은 아닙니다.
