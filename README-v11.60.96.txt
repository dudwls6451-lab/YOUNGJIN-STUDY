항공안전법: 법률 제21822호, 2026-09-17 시행
항공안전법 시행규칙: 국토교통부령 제1601호, 2026-07-01 시행
  별표 10: 항공종사자에 대한 행정처분기준, 2025-12-05 개정
항공안전법 시행령: 대통령령 제36476호, 2026-07-09 시행
  별표 5: 과태료의 부과기준, 2026-06-30 개정

요청하신 이름으로 영역을 만들되 실제 근거는 구분했습니다.
형사벌칙·벌금은 항공안전법 본문, 항공종사자 행정처분은 시행규칙 별표 10,
과태료 차수별 부과기준은 시행령 별표 5에 근거합니다.
형사벌 문제는 법정형, 차수별 처분·과태료 문제는 감경·가중 전 개별기준을 묻습니다.
법정 상한과 1차 위반의 개별 부과액을 혼동하지 않도록 설명을 넣었습니다.
2026-11-13 시행 예정 조항은 출제하지 않았습니다.
핵심 범위를 선별한 학습지이며 모든 제재 조항을 망라한 자료는 아닙니다.
과태료 가중기간의 개정 전 처분에는 부칙상 별도 경과기준이 있으므로,
과거 처분 사례에 현재 일반기준을 일괄 소급해 적용하는 자료로 사용하지 않습니다.

기능
- 영역별 출제 및 1차 / 2차 / 3차·3차 이상 / 차수 없는 기준 필터
- 학습: 즉시 채점·해설 / 시험: 마지막 일괄 채점
- 10·20·50문항 또는 선택 범위 전체 출제, 동일 문항 중복 없음
- 전체 / 미풀이 / 누적 오답 / 즐겨찾기 범위 선택
- 해설마다 근거 조문, 법령 링크와 확인 기준일 표시
- 120개 기준의 비교표: 위반행위·조문·금액·기간 검색
  차수형 기준은 한 행에서 1차·2차·3차를 비교할 수 있습니다.
  비교표 검색은 표만 검색하며 문제 출제 범위는 위 영역·차수 설정을 따릅니다.
- 기존 문제은행의 정오답·즐겨찾기·오류 신고·학습 기록 저장 기능 사용
- 결과 화면에서 학습지로 복귀, 진행 중 나가기 확인 유지
