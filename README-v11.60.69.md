# Aviquestionbank v11.60.69 — 정답률 경고와 회독 수

v11.60.67 이상 사이트에 적용하는 추가 패치입니다. v11.60.68의 과목별 진도 상세 기능도 포함합니다. ZIP의 `index.html`과 `assets/` 파일을 저장소의 같은 경로에 추가·덮어쓰고 배포하세요.

## 추가 기능

- Study Unit의 정답률이 해당 과목에 저장한 정답률 목표보다 낮으면 박스의 배경·테두리·진도 막대를 붉은색으로 표시합니다. ‘정답률 목표 N% 미달’ 문구도 함께 나옵니다.
- 단계별 보기에도 같은 기준을 적용합니다.
- 목표와 같거나 높으면 일반 색상으로 표시합니다. 미학습 단원은 ‘미학습 · 정답률 미집계’로 표시합니다. 목표에 포함하지 않은 과목에는 목표 미달 경고를 적용하지 않습니다.
- 경고는 반올림 전 실제 비율로 판정합니다. 단원별 정답률은 소수점 둘째 자리까지 버림 표시하여, 목표보다 낮은 비율이 반올림되어 목표와 같은 값으로 보이는 혼동을 줄였습니다.
- 단원마다 ‘완료 2회독 · 3회독 8 / 20문항’처럼 완료 회독 수와 다음 회독의 진도를 표시합니다.

## 회독 계산

**저장된 공부 기간 안의 풀이 기록 기준**입니다. 단원의 모든 고유 문제를 각각 한 번 풀어야 1회독, 각각 두 번 풀어야 2회독으로 셉니다. 정답·오답 모두 풀이로 인정합니다. 특정 문제만 여러 번 반복하면 전체 회독 수는 올라가지 않습니다.

예를 들어 두 문제를 각각 3번·2번 풀었다면 ‘완료 2회독 · 3회독 1 / 2문항’입니다. 한 문제만 100번 풀고 다른 문제는 풀지 않았다면 ‘완료 0회독 · 1회독 1 / 2문항’입니다.

서버·기기에 중복된 같은 문제·같은 시각의 기록은 한 번만 셉니다. 단계에 연결된 문항이 아직 전부 로드되지 않았다면 회독 집계를 보류한다는 안내를 표시합니다. 날짜별 풀이 기록이 없는 과거 기록은 소급 집계하지 않습니다.

기존 공부 기간·목표와 계정 동기화 형식을 유지하며, 새 SQL이나 설정 저장은 필요하지 않습니다.
