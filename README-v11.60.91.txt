Aviquestionbank v11.60.91 — 교재 문제풀이 단계별 선택

적용
v11.60.89 또는 v11.60.90까지 적용된 기존 GitHub 저장소에 이 ZIP의 내용을 경로 그대로 덮어쓰세요. ZIP 자체를 업로드하는 방식이 아닙니다. 변경 파일 7개만 들어 있습니다. 기존 파일·학습기록을 삭제할 필요가 없습니다. 배포 후 웹페이지/앱을 새로 열어 주세요. 별도 SQL·Python 설치·APK 재빌드는 필요 없습니다. v90의 반복 풀이 일일 목표 카운트 수정도 포함합니다.

새 기본 화면
교재 문제풀이에서 다음 교재를 누르면 필터 화면 대신 단계별 카드 목록이 열립니다.
- 항공법규: 20단계 / 1,203문항
- 비행이론: 23단계 / 914문항
- 항공기상: 40단계 / 922문항
- 항공교통통신: 25단계 / 938문항
- 비행정보 및 관제절차: 7단계 / 1,042문항
- K-AIM: 30단계 / 1,122문항
합계 145단계 / 6,141문항입니다. 기존 단계 ID를 사용하고 K-AIM은 기존 Study Unit 번호에 따라 전체 문항을 연결합니다.

카드 내용
단계 제목, 진도율, 정답률, 완료 회독·다음 회독 진행, 풀이·정답·오답 횟수와 ‘이 단계 풀기 / 오답만 풀기’를 표시합니다. 회독별 게이지 색상과 정답률 목표 미달 경고를 유지합니다. 학습 문제는 이론 읽음/단계시험 통과 여부와 관계없이 선택할 수 있습니다.

통계 기준
공부기간이 설정돼 있으면 그 기간의 기록으로 표시합니다. 공부기간이 없으면 누적 기록을 사용합니다. 오답만 풀기는 같은 기준에서 한 번이라도 틀린 문항을 선택합니다. 오류 신고·미채점 등 출제 제외 조건을 적용하므로 카드 전체 문항 수와 출제 가능한 수가 다를 수 있습니다. 시험 제외 표시는 시험에만 적용합니다.

탐색과 기존 기능
- 문제/결과 화면의 ‘단계 목록으로’를 누르면 선택했던 교재·단계로 돌아옵니다.
- 결과의 ‘처음으로’도 해당 단계 목록으로 돌아옵니다.
- 항공법규 모의고사 28회는 ‘모의고사’ 탭에 분리했습니다. 학습·오답 풀이·시험을 선택할 수 있습니다.
- 기존 필터는 ‘직접 범위 선택’으로 열 수 있습니다.
- 다른 교재와 항공사 대비과정의 기존 선택 방식은 유지합니다.
- 마이페이지의 해당 6개 교재도 같은 단계 목록을 사용합니다.

유지 사항
문제 내용·정답·이미지·문제 ID·기존 학습영역 태그와 저장된 학습기록을 변경하지 않습니다. 이전 20건 오류 수정, 회독 목표, 오늘 총 풀이 수와 v90 일일 반복 풀이 카운트를 유지합니다. 추가 서버 설정이나 기록 초기화는 필요 없습니다.

검증
모바일/PC 화이트·다크 모드와 기본 진입, 누적/기간별 집계, 오답 선택, 목록 복귀, 모의고사 시험, 직접 범위 선택, 다른 교재 흐름, 계정 분리 등 40개 실제 UI 검증 통과.
145개 단계 × 2개 화면 폭에서 총 290개 native 출제 범위 검증 통과.
마이페이지와 단계 목록의 문항 합계 및 6,141개 고유 연결 검증 통과.
v90 반복 풀이 카운트 등 계산 회귀 검증 9건 통과.
