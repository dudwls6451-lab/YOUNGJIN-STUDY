원문과 범위
TalkFile_JEPPESEN AIRWAY MANUAL (251113).pdf
ICAO Rules of the Air · Annex 2
5.1.1.1–5.1.1.28, 본문·도해 p.1134–1145
첨부본의 그림을 직접 발췌했습니다. 새 그림을 생성하거나 좌우 반전하지 않았습니다.
본문 설명은 한국어로 작성하고, 원문 항목번호 및 본문·그림 페이지를 문항별로 기록했습니다.
일부 그림은 해당 제목·본문의 다음 페이지에 있어 본문 쪽과 도해 쪽을 구분했습니다.
이번 범위는 지상 유도요원→항공기 신호입니다.
조종사→유도요원 및 ARFF 비상통신 신호는 이번 범위에 포함하지 않았습니다.

문항
원문 도해 34종, 객관식 68문항입니다.
각 신호마다 두 유형을 제공합니다.
1. 그림·동작 설명 → 신호 의미 선택
2. 신호 의미 → 그림·동작 설명 보기 선택
각 문항은 4지선다이며, 그림 보기의 대체텍스트에 정답 명칭을 넣지 않았습니다.
정상·긴급 정지의 속도, 브레이크의 손 펴기·쥐기, 초크 및 전원 신호의 이동 방향처럼
정지 그림만으로 구별하기 어려운 동작은 설명을 함께 표시했습니다.
계단 개폐는 원문처럼 하나의 신호로 다루며, 임의로 열기·닫기 신호를 나누지 않았습니다.

기능
- 분야별, 유형별, 혼합 출제
- 혼합 풀이에서는 같은 수신호를 한 번만 출제
  전체 68문항은 두 유형의 합계이며 혼합 전체 풀이는 34종에서 하나씩 고릅니다.
  68문항을 모두 풀려면 각 유형을 선택해 전체 풀이를 실행합니다.
- 학습 즉시 채점·해설, 시험 마지막 일괄 채점
- 10·20·50문항 또는 전체 선택, 실제 가능한 범위가 요청 수보다 작으면 전 범위 출제
- 미풀이·오답·즐겨찾기 범위
- 그림이 로드되기 전에는 답 선택 차단
- 필수 그림 중 하나라도 실패하면 전체 보기 차단, 다시 불러오기 제공
- 문제 도해 및 그림 보기 각각 확대
- 수신호 정리표 검색, 그림 확대, 동작 및 해설 확인
- 기존 문제은행의 학습 기록·오답·즐겨찾기·오류 신고 기능 사용
- 기존 문제·태그·오류 수정 및 약어·벌칙 학습지는 유지

방향 기준
좌·우 선회와 회전익의 좌·우 수평 이동은 조종사 관점입니다.
후진 중 선회는 항공기의 꼬리가 좌현·우현 중 어느 쪽으로 이동하는지 묻습니다.
유도요원의 오른팔·왼팔은 유도요원 본인의 신체 기준입니다.
