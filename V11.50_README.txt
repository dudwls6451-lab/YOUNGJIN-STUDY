v11.50 회원 관리 + 기능별 접근 권한

1) Supabase > SQL Editor 에서 supabase/V11.50_MEMBER_FEATURE_ACCESS.sql 실행
2) Success 확인
3) GitHub에 다음 파일 덮어쓰기/추가
   - index.html
   - assets/auth-v11-10.js
   - assets/member-admin-v11-50.js
4) 배포 후 관리자 계정으로 로그인 > 좌측/상단 '회원 관리'

기능
- 승인 대기 / 승인 완료 / 거절 탭
- 승인 / 거절 / 재승인
- 회원별 문제은행 / 이론학습 / Aviwiki / 항공사 대비 / 오답복습 / 자료실 권한 ON/OFF
- 승인 대기 숫자 배지
- 기존 회원은 별도 권한 행이 없으면 모든 일반 기능 ON (호환성)
- 관리자 계정은 기능 제한 대상에서 제외

참고
- GitHub Pages에 정적으로 배포된 파일 자체는 URL을 아는 사용자의 직접 접근까지 서버에서 차단할 수 없습니다.
- DB 데이터는 기존 RLS가 계속 보호합니다. 자료실을 강한 ACL로 제한하려면 추후 Supabase Storage private bucket으로 이전할 수 있습니다.
