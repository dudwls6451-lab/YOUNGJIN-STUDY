Aviquestionbank v11.60.82 — 항공법규 전체 학습영역 태그·단계 연결

적용 방법
1. ZIP의 압축을 풉니다.
2. 안의 파일과 폴더를 기존 GitHub 저장소의 같은 위치에 덮어씁니다. 기존 다른 파일은 삭제하지 않습니다.
3. GitHub Pages 배포가 끝나면 웹페이지를 새로고침하거나 앱을 완전히 종료한 뒤 다시 엽니다.
Python, 추가 SQL, APK 재빌드는 필요하지 않습니다.

수정 범위
검댕이 항공법규 총 1,203문항(기존 예상문제 503 + 모의고사 28회 700)을 20개 대표 학습영역으로 연결했습니다.
기존 모의고사 700문항은 회차 정보만 있고 이론 단계 question_ids에 연결되지 않아 ‘단계 미지정 문항’에 표시되던 상태였습니다.
이제 마이페이지에서 해당 교재 → 단계별을 열면 전 문항이 학습영역에 따라 표시됩니다.
각 단계에서 진도율·정답률·목표 미달 경고·회독 수를 확인하고, 이 단계 풀기·오답만 풀기를 사용할 수 있습니다.
한 문항은 대표 학습영역 하나에 연결합니다. 전체 단계의 문항 수 합계는 중복 없이 1,203문항입니다.

문제 선택 화면
과목을 ‘검댕이 항공법규’로 선택하면 ‘학습영역’ 선택창이 나타납니다.
전체 교재 또는 특정 학습영역을 고르고, Study Unit·소단원(모의고사 회차)·전체/오답/미학습 조건과 조합할 수 있습니다.
문항 상단에도 학습영역 이름이 표시됩니다.
회차별 모의고사 1~28회는 기존대로 각각 25문항입니다. 학습영역 필터는 회차별 원본 모의고사 구성을 바꾸지 않습니다.

20개 학습영역
기존 1~15단계의 ID와 이론 설명 본문은 유지하며 연결 문항과 일부 제목을 정리했습니다.
16~20단계는 기존 이론에 연결되지 않았던 모의고사 추가 주제를 모은 ‘문항 분류·풀이 안내’ 과정입니다.
16. 공항·비행장 시설 · 항행안전시설 · 등화·장애물
17. 항공사업 · 운송·사용사업 · 취급업
18. 항공보안 · 위험물 · 보안검색·기내질서
19. 항공·철도 사고조사 · 위원회·정보보호
20. 항공기 소음 · 공항소음 구역
전체 단계별 문항 수와 개별 연결 내역은 audit/항공법규_학습영역_분류내역.md 및 CSV에 있습니다.

보존되는 항목
문제 ID, 원래 교재·SU·모의고사 회차, 문제·보기·정답·해설·그림, 기존 풀이기록·학습목표·이론 읽음/통과 기록을 보존합니다.
분류를 적용할 때 학습기록을 초기화하거나 소급 재채점하지 않습니다.
기존 예상문제와 모의고사에 태그 메타데이터만 추가하며, 실행 중에는 ID별로 검토한 고정 분류표를 사용합니다.

누적 적용
v11.60.81의 보고 오류 11건 수정과 v80 운항기술기준, v79 학습 분석 등 공개 패치 파일도 함께 포함합니다.
이 ZIP은 기존 운영 저장소용 덮어쓰기 패치이며 빈 저장소용 전체 사이트는 아닙니다.

검증
1,203개 ID의 태그 누락 0, 단계 미지정 0, 단계 간 중복 연결 0을 확인했습니다.
모바일·PC에서 20개 영역 필터, 회차와의 교집합, 다른 과목 전환 시 필터 초기화를 확인했습니다.
화이트·다크 화면에서 단계 20개 표시, 2회독 표시, 목표 미달 경고, 오답만 풀기를 확인했습니다.
각 단계의 실제 문제 풀이와 단계시험 문제 범위, 28회차 원본 모의고사 25문항 구성을 확인했습니다.
모의고사 700문항의 원문 필드와 기존 15단계 이론 본문이 변경되지 않았음을 데이터 비교로 확인했습니다.
실제 운영 계정·서버 데이터는 이번 작업 중 변경하지 않았습니다.
