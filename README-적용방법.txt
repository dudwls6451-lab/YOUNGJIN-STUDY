Aviquestionbank v11.60.84 — 비행이론 전체 문항 학습영역 태그·단계 연결

적용 방법
1. ZIP 압축을 풉니다.
2. 안의 파일과 폴더를 기존 GitHub 저장소의 같은 위치에 덮어씁니다. 다른 기존 파일은 삭제하지 않습니다.
3. GitHub Pages 배포가 끝나면 웹페이지를 새로고침하거나 앱을 완전히 닫은 뒤 다시 엽니다.
Python, 추가 SQL, APK 재빌드는 필요하지 않습니다.

분류 범위
비행이론 전체 914문항 = 예상문제 589 + 모의고사 제1~13회 325문항을 기존 23개 학습영역에 연결했습니다.
기존 이론 과정은 모의고사를 단계시험에서 제외해 마이페이지에서도 단계 미지정으로 표시하고 있었습니다.
이제 모의고사를 포함한 전 문항이 대표 학습영역 하나에 연결됩니다. 단계별 문항 수 합계는 중복 없이 914문항입니다.
기존 예상문제 589개의 단계 연결, 23개 단계의 ID·제목·설명 본문은 유지했습니다.
모의고사 325문항의 문구와 보기 맥락을 검토해 영역을 지정했습니다.

사용 방법
- 마이페이지 → 비행이론 교재 박스 → 단계별: 진도·정답률·목표 미달 경고·회독 수를 확인합니다.
- 이 단계 풀기·오답만 풀기로 해당 영역을 공부합니다.
- 문제 선택 → 과목 비행이론 → 학습영역: 원하는 영역을 선택합니다.
- Study Unit·소단원(모의고사 회차)·전체/오답/미학습 조건과 함께 사용할 수 있습니다.
- 문항 상단에도 학습영역 이름이 표시됩니다.
기존 SU 9 모의고사 및 소단원 9.1~9.13, 각 회차 25문항은 그대로 유지됩니다.

보존되는 항목
문제 ID, 원래 교재·SU·소단원·회차·출처, 문제·보기·정답·해설·그림, 풀이기록 및 공부기간·목표를 보존합니다.
기존 v11.60.77의 914문항 원문 검수와 정답·그림 수정 내용도 보존합니다.
분류 설치는 학습기록을 초기화하거나 과거 풀이를 소급 재채점하지 않습니다.
기존 tags에 학습영역 태그를 추가하고 topic_id 및 theory_stage_id를 부여합니다. 실행 중에는 검토한 고정 ID 분류표를 사용합니다.
