V11.56 — Aviwiki 형광펜/필기 + 나의 필기 + 이론 공부시간 패치

기준: v11.55-kaim-learning

기능
- AVIWIKI 본문 텍스트 드래그 → 형광펜(4색)
- 선택 영역 형광펜 지우기
- 필기 모드: 펜 / 마커 / 지우개 / 색상 / 굵기 / 되돌리기 / 전체 지우기
- 필기 저장: 현재 AVIWIKI 이론 화면을 PNG 스냅샷으로 브라우저 IndexedDB에 저장
- 마이페이지 > 나의 필기: 열기 / PNG 저장 / 삭제
- 공부시간: 문제풀이뿐 아니라 교재 이론 학습 화면과 AVIWIKI 이론 상세 화면도 누적
- 10분 무입력 시 기존과 동일하게 자동 idle 처리, 스크롤은 학습 상호작용으로 인정

저장 범위
- 하이라이트/드로잉/PNG 필기: 현재 브라우저·기기 기준 로컬 저장
- 공부시간: 기존 Supabase 계정의 일별 공부시간에 서버 저장

적용
- v11.55 적용 저장소 루트에 ZIP 내용물을 폴더 구조 그대로 덮어쓴 뒤 강력 새로고침(Ctrl+Shift+R)
