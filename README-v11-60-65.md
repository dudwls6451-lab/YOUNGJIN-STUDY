# v11.60.65 — CPL Gleim OCR 줄바꿈 정리

## 적용

ZIP의 data/questions-cpl-gleim-2024-v3.json을 GitHub 저장소의 같은 경로에 덮어쓰세요. 배포 후 웹을 새로고침하거나 앱을 종료 후 다시 실행하세요. 기존 로더가 이 파일을 cache: no-store로 요청하므로 index.html이나 앱 코드를 바꿀 필요가 없습니다. APK 재설치도 필요 없습니다.

직전 v11.60.64 홈 자동 표시 패치를 포함한 다른 파일은 그대로 사용합니다. 이 패치는 CPL 데이터 정리만 포함합니다.

## 변경

CPL Gleim 893문항 전체의 문제 본문·보기·해설을 처리했습니다.

- 문제 본문 794개, 보기 1,023개, 해설 893개에서 줄바꿈을 정리했습니다.
- 일반 문장은 단어 사이 공백으로 연결했습니다. Surveillance-Broadcast, Low-Level처럼 하이픈 뒤에서 끊긴 표현은 하이픈에 바로 이어 붙였습니다.
- GIVEN의 계산 조건, 번호 목록의 항목 구분, 수식·표·도표의 행 구분은 유지했습니다. 목록 항목 안에서 불필요하게 끊긴 문장은 이어 붙였습니다.
- 보기별 오답 해설은 문단을 나누어 읽기 쉽게 정리했습니다.

## 검증

893문항 모두 정리 전후의 공백을 제외한 문자가 완전히 같은지 검사했습니다. 정답, 문항 ID, 문항 순서, 보기 ID와 순서, 그림 경로 및 다른 메타데이터가 유지됨을 확인했습니다. 기존 학습 기록과 연결되는 ID를 유지하므로 기록을 초기화하지 않습니다.

PC 1440px / 모바일 390px Chromium에서 앱 본체로 893문항을 불러오고, 일반 문장·하이픈 연결·계산 조건·수식이 있는 5개 대표 문항의 표시·해설·채점·진도 기록과 밝은/어두운 테마를 확인했습니다. 계정과 다른 과목 데이터는 테스트 대역을 사용했으며 실제 사용자 계정이나 배포 서버를 수정하지 않았습니다.

기존 OCR 문구의 의미·오탈자·수식 내용은 이번 작업의 변경 대상이 아닙니다. 데이터 검증 결과와 브라우저 검증 결과를 함께 첨부했습니다.
