V11.57 — AVIWIKI 클라우드 필기 + 안전한 필기 박스

기준 버전
- v11.56.1 AVIWIKI 모바일 도구 수정 패치

중요: 최초 1회 Supabase 설정
1. Supabase Dashboard > SQL Editor를 엽니다.
2. supabase/V11.57_AVIWIKI_CLOUD_NOTES.sql 내용을 실행합니다.
   - private bucket: aviwiki-notes
   - table: public.aviwiki_notes
   - 본인 파일/메타데이터만 읽기·쓰기·삭제 가능한 RLS 정책 포함
3. 그 다음 ZIP 내용을 GitHub 저장소 루트에 폴더 구조 그대로 덮어씁니다.
4. 배포 후 Ctrl+Shift+R 강력 새로고침.

변경 사항
- 필기 저장: 브라우저 IndexedDB 대신 Supabase Storage에 저장
- 저장 이미지는 WebP 압축(지원 안 될 경우 PNG)
- 마이페이지 > 나의 필기: 로그인 계정 기준으로 기기간 동기화
- 필기 영역: 화면 전체가 아니라 AVIWIKI 본문 안 고정 높이 네모 박스
- 필기 박스 안에 이론 텍스트가 들어가며 내부 스크롤
- 필기 모드 진입 시 기본 도구는 ✋ 이동: 박스 안을 먼저 안전하게 스크롤
- 펜/마커/지우개 선택 시에만 캔버스가 터치를 잡음
- 박스 밖 화면은 항상 정상 스크롤/터치
- 필기 저장 시 현재 보이는 네모 박스 화면만 캡처해 파일 크기 축소
- 기존 형광펜, 공부시간 누적 기능 유지

주의
- SQL을 실행하지 않으면 앱은 '클라우드 필기 저장 준비가 필요합니다'라고 표시합니다.
- 형광펜/작업 중 벡터 필기는 기존처럼 해당 브라우저의 작업 상태에 남고, '필기 저장' 결과물만 클라우드 동기화됩니다.
