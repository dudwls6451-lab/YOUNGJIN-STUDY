# Aviquestionbank v11.60.72 — 비행정보 및 관제절차

## 적용 방법

**v11.60.71까지 적용한 사이트용 추가 패치입니다.** ZIP을 풀어 `index.html`, `assets/`, `data/`의 파일을 저장소의 같은 경로에 추가·덮어쓴 뒤 배포하세요. 기존 폴더를 삭제하지 말고 파일을 병합해야 합니다.

문제 풀이 교재와 이론 학습 교재 목록에서 **비행정보 및 관제절차**를 선택합니다. 기존 K-AIM·항공교통통신과 구별되는 별도 교재입니다.

## 추출 범위

사용자가 제공한 `AIM_ocr.pdf` 340쪽을 기준으로 추출했습니다. 원본에 표시된 판본은 2024년 2월 19일 초판 1쇄입니다.

| 장 | 문제 수 | 이론 본문 인쇄 쪽 |
| --- | ---: | --- |
| 1. 공중항법 | 102 | 7–15 |
| 2. 항공등화 및 공항표지시설 | 93 | 33–43 |
| 3. 공역 | 58 | 63–69 |
| 4. 항공교통관제 | 260 | 83–109 |
| 5. 항공교통절차 | 323 | 167–196 |
| 6. 비상절차 | 53 | 265–270 |
| 7. 비행안전 | 153 | 283–302 |
| 합계 | **1,042** | **110쪽** |

- 예상문제는 7개 Study Unit, 30개 소단원으로 분류했습니다. 소단원마다 다시 시작하는 원문 문제 번호를 유지하고 고유 문제 ID를 별도로 부여했습니다.
- 문제·보기·페이지별 정답표·해설을 추출했습니다. 책에 공통으로 제시된 해설은 관련 앞선 문제에도 ‘교재의 공통 해설’로 연결했습니다. 별도 해설이 없는 문항에는 그 사실과 원문 정답을 표시합니다.
- 모든 문제를 원문 이미지로도 보존했습니다. 두 문제는 페이지를 넘어 이어져 총 1,044개의 문제 이미지가 있습니다. 문제 이미지에서 해설·페이지 하단 정답표는 제외했습니다.
- 그림·기호가 필요한 문항에는 원문 그림을 함께 표시합니다. 도형으로 된 보기에는 ‘원문 그림의 ①’ 같은 선택지를 사용합니다.
- 이론 본문 110쪽은 요약본으로 대체하지 않고 원문 페이지의 표·그림과 OCR 본문 텍스트를 모두 포함했습니다. 7개 장을 이론 7단계로 연결했습니다.
- 전체 340쪽의 페이지 이미지와 OCR 텍스트도 추출 자료에 보존했습니다. 원본 PDF 자체를 중복 포함하지는 않습니다.

## 사용 기능

- 일반 학습·시험·오답 복습·즐겨찾기·오류 신고에서 새 교재 사용
- 7개 장 및 30개 소단원 필터
- 이론 본문을 읽고 장별 문제에서 10문항 쪽지시험 응시, 80% 이상 정답 시 다음 단계 해제
- 홈의 새 교재 자동 표시 및 마이페이지 목표 설정
- 마이페이지의 장·단계별 진도, 정답률 경고, 회독, 해당 범위 전체·오답만 풀기
- ‘원문 문제 확인’과 정답 확인 후 ‘교재 해설 원문’ 보기
- 원문 그림·표를 누르면 앱 안의 확대 창에서 확대·화면 맞춤·닫기 사용. 모바일에서는 확대 상태로 열리며 가로·세로로 이동해 읽을 수 있습니다.

기존 학습 목표와 풀이 기록 형식을 유지합니다. 새 SQL이나 목표 초기화는 필요하지 않습니다. 원문 이미지 파일들은 해당 화면에서 필요할 때 불러옵니다.

## 대조 및 검증

30개 소단원에서 문제 번호가 연속되는지 검사했고, 1,042개 문제와 페이지 하단 정답표의 번호를 모두 대조했습니다. 정답 OCR에서 `@`로 읽힌 15개는 원문 정답표 이미지로 확인하여 ④로 복구했습니다. 보기 번호가 잘못 인식된 3개 행도 원문에서 확인하여 교정했습니다. 좌우 열 순서와 4개 보기 번호를 정리했으며, 보기 뒤에 섞인 보충표·해설은 해설로 이동했습니다.

1,385개 원문 이미지 파일의 존재·이미지 형식을 검사했습니다. 이론 110쪽 및 장별 문제 ID가 전체 1,042문항을 빠짐없이 연결하는지도 확인했습니다.

Chromium의 PC 1440px·모바일 390px에서 실제 수정 본체와 추출 데이터를 함께 실행했습니다. 1,042문항 로딩, 30개 소단원, 첫 장 102문항 범위 출제, 원문 문제·해설 이미지 표시, 시험 중 해설 숨김, 첫 이론 단계의 실제 10문항 만점 합격, 전체 7단계·110쪽 표시를 확인했습니다. 다크·화이트 모드 및 확대 창도 검사했습니다.

인증·Supabase 및 관련 없는 기존 문제 피드는 테스트용입니다. 운영 서버 배포나 실제 계정의 동기화 검사는 실행하지 않았습니다. 자세한 결과는 validation JSON에 포함합니다.

정답은 **교재 원문 정답표 기준**입니다. 현행 법령·절차에 맞춰 교재의 모든 답을 재판정하는 작업은 별도이며, 이번 패치에서 원문 정답을 임의 변경하지 않았습니다. OCR 문장에는 스캔 인식 오차가 남을 수 있으므로 확인이 필요한 표기·표·기호는 함께 제공한 원문으로 대조할 수 있습니다.
