# PilotBank v11.60.8 — Unanswered Submit Confirmation Patch

Base: v11.60.7 result-question-expand one-shot patch.

## Changes
- Exam-like flows (including theory stage tests / mock-style tests): when the final submit action is pressed with unanswered questions, show a confirmation dialog before grading/submission.
- The dialog shows the unanswered count and warns that unanswered questions are treated as incorrect.
- Cancel returns to the exam without changing any answers; OK continues submission.
- Weekly Ranking: the same unanswered warning is shown on manual submission, while the existing irreversible-submission warning is retained.
- Weekly Ranking deadline auto-submit remains automatic and is not blocked by a confirmation dialog.
- v11.60.7 result review expansion remains unchanged.
