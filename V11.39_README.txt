항공 문제은행 v11.39 — Supabase 학습데이터 전환 패치

이번 버전부터 승인된 Supabase 계정의 학습정보는 브라우저 LocalStorage가 아니라 Supabase를 원본으로 사용합니다.
기존 LocalStorage 학습기록은 가져오지 않으므로 새 DB 기록에서 0부터 시작합니다.

[적용 순서]
1. Supabase Dashboard → SQL Editor → Create a new snippet
2. 이 ZIP의 supabase/V11.39_LEARNING_DATA.sql 전체를 붙여넣고 Run
3. "Success. No rows returned" 또는 정상 성공 메시지 확인
4. GitHub 저장소에 다음 파일을 업로드/덮어쓰기
   - index.html
   - assets/app-v11-19.js
5. GitHub Pages 배포 완료 후 Ctrl+F5

[저장되는 데이터]
- user_question_progress : 문제별 누적 풀이/정답/오답/최근결과/오류신고
- user_question_flags    : 즐겨찾기 / ! 시험모드 제외
- user_attempts          : 매 풀이의 상세 이력
- user_theory_progress   : 이론 학습 단계 진도/쪽지시험 기록
- user_exam_sessions     : 완료한 학습/시험 세션 점수 요약

[RLS]
- 일반 사용자는 자기 user_id 행만 읽고 쓸 수 있습니다.
- profiles.is_admin=true인 관리자는 모든 사용자의 학습 데이터를 읽을 수 있습니다.

[확인 방법]
1. approved 테스트 계정으로 로그인
2. 문제 1개 풀이 + 즐겨찾기/! 중 하나 변경
3. Supabase Table Editor에서 위 테이블에 해당 사용자 UUID 행이 생기는지 확인
4. 사이트 새로고침 후 통계/표시가 유지되는지 확인
5. 가능하면 다른 브라우저에서 같은 계정으로 로그인하여 동일 기록 확인

[참고]
- 기존 김영진_시험용 legacy 계정은 이전 방식(LocalStorage)을 유지합니다.
- Supabase 가입 사용자는 v11.39부터 클라우드 DB를 사용합니다.
