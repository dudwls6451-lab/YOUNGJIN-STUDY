# Aviquestionbank v11.60.49 · 이스타항공 대비 과정

v11.60.48 홈·오늘의 퀴즈·다크/화이트 테마 패치 위에 적용합니다.

## 적용

ZIP의 `index.html`, `assets/`, `data/`를 기존 문제은행 루트에 덮어쓰고 배포 후 강력 새로고침하세요. 새 본체는 `assets/app-v11-60-49.js`이며 index.html에서 연결합니다. 기존 진도/풀이 이력 저장 함수를 사용하며 새 DB 테이블을 추가하지 않으므로 추가 SQL은 없습니다. v11.60.48의 SQL을 이미 실행했다면 다시 실행할 필요도 없습니다.

현재 APK는 사이트 접속 방식이므로 웹사이트에 이 패치를 배포하고 앱에서 새로고침하면 이스타항공 과정이 반영됩니다. APK를 다시 만들 필요는 없습니다.

## 학습·채점

- 첨부 자료의 문제·보기·정답·모범답안·해설·선지별 분석을 보존합니다.
- 과거 응시자의 `내 답`, 정답률, 부분점수, 저장/의견 보내기 등의 화면 문구는 새 문제 데이터에서 제거했습니다.
- 객관식은 2점, 단답형은 4점으로 회차당 원래 100점 구성입니다.
- 객관식 학습은 선택 후 정답·해설을 표시합니다. 실전은 전체 답안 제출 전까지 정답·해설을 숨깁니다.
- 단답형은 직접 작성하고 모범답안과 비교해 0~4점으로 자가채점합니다. AI 자동채점이나 문구 일치 자동판정을 사용하지 않습니다. 채점 확정 후 해당 풀이의 점수는 잠깁니다.
- 진행 중인 답안과 제출 후 채점 중인 결과를 기기별로 저장해 새로고침 후 이어 확인할 수 있습니다.
- 문항별 풀이/정오답 기록과 완료된 회차 결과는 기존 저장 함수에 연결했습니다. 부분점수 단답형은 정답 4점에 도달하지 못하면 오답 기록에 포함합니다.
- 단답형 오답 복습은 이스타항공 과정의 회차별 오답 버튼에서 진행합니다. 기존 객관식 전용 공통 플레이어에는 단답형을 넣지 않아 빈 보기 화면이 나오지 않도록 처리했습니다.
- 자유학습에는 기존 항공사 전용 과정과 동일하게 이스타항공 전용 문항을 섞지 않습니다.
- 이스타항공 풀이 화면을 기존 학습시간 집계에 연결했습니다.

## 그림 누락

각 회차 44번은 실제 기상기호 그림이 필요한 문항이지만 세 첨부 텍스트에 그림이 없습니다. 해당 3문항은 원문과 모범답안을 보존하며 자료 보완 필요로 표시합니다. 점수와 오답 기록에는 포함하지 않으므로 현재 회차별 채점 가능 점수는 96점, 그림 누락 미채점은 4점으로 구분해 표시합니다.

1·2회차 43번의 유도로 표지 그림도 첨부되지는 않았으나 문항에 표지 형태가 문자로 설명되어 있습니다. 문자 설명으로 학습·채점하고 그림 미첨부 안내를 함께 표시합니다. 그림을 임의로 생성하거나 번호별 기상기호를 추측하지 않았습니다.

## 검증 범위

135개 고유 ID, 회차별 1~45번, 객관식 4보기/정답키, 단답형 모델 답안, 첨부 로고 바이트 일치, 기존 HTML ID 보존을 확인했습니다. Chromium PC·태블릿·모바일에서 홈/오늘의 퀴즈 회귀 테스트와 이스타항공 과정의 회차 매핑, 실전 정답 숨김, 객관식/단답형 점수, 그림 누락 미채점, 중단/새로고침/결과 이어보기, 오답 복습을 검증했습니다.

정답·법규·항공 지식 자체를 독립적으로 재검수한 패치는 아닙니다. 첨부 정답표와 해설을 기준으로 이전했습니다. 테스트는 로그인 API 대역과 로컬 진도 저장을 사용했으며 운영 Supabase 및 외부 기능 모듈 전체의 실제 통합 검증은 하지 못했습니다.

- `validation-import.json`: 데이터/회차/로고/ID 검증
- `validation-course.json`: 과정 동작 검증
- `validation-home-regression.json`: 홈·퀴즈·테마 회귀 검증
- `data/eastar-rounds-v11-60-49.json`: 검토용 추출 데이터
