# v11.60.6 전체 검수 과목 띄어쓰기 통합 패치

이 패치는 사이트 저장소의 루트에서 압축을 풀어 기존 파일을 덮어쓰면 한 번에 적용된다.

- 비행이론 914문항
- 공중항법 879문항
- K-AIM 1,122문항
- 검댕이 항공법규 503문항
- 항공교통통신 938문항
- 합계 4,356문항

## 띄어쓰기·OCR 문장 변경 문항

- 비행이론 177문항
- 공중항법 221문항
- K-AIM 865문항
- 검댕이 항공법규 215문항
- 항공교통통신 445문항

검사 범위는 문제문, 보기, 해설이다. 과목별 기존 정답 수정과 그림 연결도 모두 포함한다.

## 적용 방법

1. ZIP 파일의 압축을 푼다.
2. 압축을 푼 내부의 `data`, `assets`, `figures`, `index.html`을 GitHub Pages 저장소 루트에 그대로 덮어쓴다.
3. 변경된 파일을 커밋하고 배포한다.
4. 브라우저에서 강력 새로고침한다.

## 검증 결과

- 5개 검수 과목 4,356문항 JSON 로드 성공
- 과목별 ID 중복 없음
- 정답 및 보기 구조 검사 통과
- 통합 기본 데이터 3,438문항 로드 성공
- K-AIM 앱 내장 데이터 동기화 완료
- JavaScript 구문 검사 통과

## 남은 원본 복원 표시

K-AIM 확장 수록분 76문항은 원본 이미지에서 문제문 또는 보기의 추가 판독이 필요한 상태다. 임의로 내용을 추정하지 않고 기존 `extraction_review_required` 표시를 유지했다. 해당 문항도 복원된 범위 안에서는 이번 띄어쓰기 교정을 적용했다.
