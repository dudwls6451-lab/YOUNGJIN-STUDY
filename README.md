# Aviquestionbank v11.60.48

v11.60.47 메뉴 패치 위에 적용하는 홈·오늘의 퀴즈·테마 패치입니다.

## 적용

1. Supabase SQL Editor에서 `V11.60.48_DAILY_QUIZ.sql`을 한 번 실행합니다.
2. ZIP 안의 `index.html`과 `assets/` 내용을 기존 문제은행 루트에 덮어씁니다.
3. 사이트 배포 후 강력 새로고침합니다.

새 본체 파일은 `assets/app-v11-60-48.js`입니다. 기존 본체의 문제 데이터 및 오류 교정 로직을 이어받고, index.html이 새 파일을 로드하도록 변경했습니다. 파일 이름만 보고 이전의 다른 v11.60.48 패치와 혼용하지 마세요. 이 패치는 2026-10-14 AWOS 메뉴 패치 흐름용입니다.

## 동작

- 홈에는 오늘의 학습 시작/학습시간과 교재별 학습 현황만 표시합니다.
- 학습모드 선택 화면은 홈에서 숨기며 메뉴의 학습 허브에서 열 수 있습니다.
- 한국 시간 기준 하루 첫 접속에 랜덤 5문항이 먼저 나옵니다. 정답 여부와 관계없이 5문항 모두 답하면 홈으로 들어갈 수 있습니다.
- 정답 선택 전에는 정답과 해설을 표시하지 않습니다. 선택 후 정답·해설과 다음 문제 버튼을 표시합니다.
- 출제 제외/오류 신고/정답 미확정/추출 검토 필요 문항과 도표가 필수인 문항은 일일 퀴즈에서 제외합니다. 5개 ID는 중복 없이 추출합니다.
- 새로고침 시 같은 문제와 풀이 위치를 이어갑니다. 완료한 날에는 재접속 시 홈으로 바로 들어갑니다. 다음 날짜에는 새 퀴즈를 생성합니다.
- 오늘의 퀴즈 기록은 별도 테이블에 저장합니다. 일반 문제풀이 진도/성적에는 중복 합산하지 않습니다.
- SQL 적용 후 Supabase 로그인 계정의 문제·답변·완료 상태는 계정 기준으로 동기화됩니다. SQL 미적용이나 통신 오류 시에는 해당 기기에 저장하며 퀴즈 화면에서 기기 저장 상태를 안내합니다. 레거시 로그인 계정은 기기 저장을 사용합니다.
- 상단의 다크/화이트 버튼으로 전환하며 해당 브라우저에 선택이 저장됩니다.
- 기존 화면 스타일의 중립색 고정값을 공통 테마 색상으로 정규화합니다. 동적으로 추가되는 스타일과 인라인 색상도 처리합니다. 형광펜 표시·그림·SVG/Canvas 색상은 보존합니다.
- 헤더의 배경 필터를 제거해 메뉴 높이 붕괴를 방지하면서 기존 로그인·커뮤니티의 header-nav 연결을 유지합니다. 작은 모바일 화면은 타이머/테마/로그아웃 버튼을 두 번째 줄에 배치합니다.

## 검증

실제 Chromium에서 1440/946/390/360px로 홈, 퀴즈 진입/완료/재접속, 메뉴 전환, 다크·화이트 전환 및 헤더 겹침을 확인했습니다. 기존 고정 흰색 글자+흰색 배경의 테마 회귀 테스트도 수행했습니다.

`validation.json`에 검증 범위를 기록합니다. 로그인/문제 API는 테스트 대역을 사용했고, 외부 기능 모듈 전체 및 운영 Supabase를 실제 연결해 검증한 것은 아닙니다. 두 기기 동기화와 한국 날짜 변경은 모의 DB로 테스트했습니다. 화면 캡처는 내부 확인에만 사용했습니다.
