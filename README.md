# v11.60.61 — 공부 기간·목표의 계정 동기화

저장소의 같은 경로에 덮어쓰고 배포하세요. SQL 실행이나 APK 재설치는 필요 없습니다. v11.60.60의 일일 목표·알림과 기존 문제 정정을 포함합니다.

적용 순서:
1. 이 웹 패치를 GitHub에 배포합니다.
2. 기존 목표가 있는 모바일에서 앱을 닫았다가 다시 열고 로그인합니다. 기존 기기 설정을 자동으로 계정 저장소에 가져옵니다.
3. 컴퓨터에서 같은 계정으로 접속한 뒤 새로고침합니다. 모바일에 있던 공부 기간·선택 교재·목표 진도율/정답률·알림 사용 여부가 반영됩니다.
4. 홈 집중학습 항목 선택도 같은 계정으로 동기화됩니다.

동기화 동작:
- 로그인 계정의 Supabase Auth user_metadata에 전용 키 aviquestionbank_study_settings_v1로 작은 설정 객체를 저장합니다. 사용자 이름 등 다른 메타데이터는 유지합니다. 비밀번호·이메일·권한을 변경하지 않습니다.
- 최초 진입·창 복귀·온라인 복귀와 표시 중 60초 간격으로 서버 설정을 조회합니다. 변경 저장과 기간 해제는 즉시 서버에 반영합니다.
- 기존 로컬 설정은 서버에 해당 항목이 아직 설정되지 않은 경우 자동 이관합니다. 컴퓨터에서 집중학습 교재만 먼저 저장했어도 모바일의 기존 공부 기간을 따로 가져올 수 있습니다.
- 서버의 기간 해제를 명시적으로 저장하므로 오래된 다른 기기가 해제된 목표를 자동 부활시키지 않습니다.
- 연결 실패 시 변경분을 기기에 남겨 재시도합니다. 자동 재시도 중 다른 기기의 변경을 발견하면 이를 덮어쓰지 않고 「이 기기 설정 서버에 저장」 또는 「서버 설정 불러오기」를 선택하도록 표시합니다.
- 사용자가 직접 저장하면 해당 항목에 대한 새 변경으로 처리합니다. 설정 변경을 완전히 동시에 전송한 경우 마지막 서버 저장이 기준이 됩니다. 이 저장소는 트랜잭션 기반 다중 기기 동시 편집 잠금은 제공하지 않습니다.
- 작성 중인 폼 입력은 자동 동기화가 덮어쓰지 않으며, 홈의 계산과 알림 상태는 가져온 설정으로 갱신합니다.
- 설정 동기화와 학습 풀이 이력 동기화는 분리됩니다. 기존 user_attempts를 이용한 기간별 진도·정답률 조회는 유지합니다. 오늘의 퀴즈 게이트는 기존처럼 별도입니다.
- 알림 사용 설정은 공유되지만 Android 알림 권한·정확한 시간 권한은 각 기기에서 별도로 허용해야 합니다. 닫힌 앱은 마지막 확인 학습 기록 기준이라는 기존 제한도 유지됩니다.

# v11.60.60 — 선택 교재와 일일 목표·미달성 알림

같은 경로로 저장소에 덮어쓰고 배포하세요. SQL 변경은 없습니다. 이번 묶음의 Android 1.0.2는 앱을 닫은 상태의 예약 알림을 추가하므로 한 번 설치해야 합니다. 이후 일반 웹 수정은 GitHub 배포로 반영됩니다.

마이페이지 → 공부 기간과 목표 → 목표 교재 체크 → 기간·목표 저장. 홈의 집중학습 교재 선택과 목표 교재 선택은 각각 조절할 수 있습니다.

계산과 표시:
- 선택 교재별 문항 수 × 목표 진도율을 올림하여 목표 문항 수를 구한 뒤 합산합니다. 진도 목표 100%면 선택 교재의 전체 문항 수를 그대로 합산합니다.
- 일일 문제 수 = 합산 목표 문항 수 ÷ 시작일·종료일을 포함한 공부 일수, 소수점 올림.
- 한국 시간 기준으로 그 공부 기간에 처음 푼 고유 문항만 진도에 포함합니다. 같은 날 또는 다음 날 같은 문항을 반복해서 풀어도 일일 진도가 늘어나지 않습니다. 정답·오답은 모두 풀이로 인정합니다.
- 교재별 목표 분량을 초과한 풀이가 다른 선택 교재의 부족분을 대신하지 않습니다. 남은 전체 목표가 일일 기본 분량보다 적으면 오늘 목표를 남은 분량으로 줄입니다.
- 홈에 오늘 풀이 수·목표 문항 수·달성률을 표시합니다. 18시 이후 미달성 시 경고가 계속 표시되고 목표 달성 즉시 사라집니다.
- 공부 기간 내 미달성 상태일 때 18·20·22·23시마다 시간대당 한 번 알림을 표시합니다. 놓친 여러 시간대 알림을 한꺼번에 재생하지 않습니다. 기간 전·종료 후·목표 달성·알림 해제 상태에서는 알림을 보내지 않습니다.
- 기존 기간별 정답률과 누적 기록은 유지됩니다. v59 설정은 기존 goals에 있는 교재를 선택한 상태로 읽습니다.

알림 환경:
- 새 APK: 마이페이지의 「알림 권한 설정」을 눌러 Android 알림과 정확한 시간 알람 권한을 허용하세요. 권한을 허용하지 않으면 시스템 알림이 차단되거나 예약 시간이 지연될 수 있습니다.
- 일반적인 앱 닫기 후에도 Android가 예약 알림을 처리합니다. 재부팅·앱 업데이트 후 예약을 복원합니다. 시스템에서 앱을 강제 중지하거나 제조사 절전 정책이 동작하면 수신이 제한될 수 있습니다.
- 닫힌 앱의 알림은 마지막 앱 기록을 기준으로 판단합니다. 다른 기기에서 공부했다면 앱을 열어 이력을 갱신해야 해당 진도가 반영됩니다. 로그인 정보나 서버 토큰을 네이티브 알림 저장소에 넘기지 않습니다.
- 웹·이전 APK는 페이지가 실행되는 동안 화면 내 알림을 표시합니다. 지원하는 브라우저에서 알림 권한을 허용하면 웹 시스템 알림도 표시합니다. 닫힌 브라우저에 웹 푸시를 보내는 서버 기능은 포함하지 않습니다.
- 서버 이력을 불러오는 중이거나 실패한 상태에서는 확정되지 않은 집계로 예약 경고를 보내지 않도록 예약을 일시 중지합니다. 조회 성공 후 재설정합니다.

# v11.60.59 — 공부 기간별 진도·정답률과 교재 목표

저장소에 압축을 풀어 같은 경로로 덮어쓴 뒤 배포하세요. APK 재설치·SQL 변경은 필요 없습니다. v11.60.58 메뉴 수정과 v11.60.57 문제 정정을 포함합니다.

마이페이지 상단의 「공부 기간과 목표」에서 시작일·종료일과 교재별 목표 진도율·정답률을 입력한 뒤 「기간·목표 저장」을 누르세요. 홈의 교재 선택은 기존 「집중학습 항목」에서 설정합니다.

- 한국 시간 기준 시작일 00:00부터 종료일 23:59:59까지 집계합니다. 미래 기간도 설정할 수 있습니다.
- 기간 진도율 = 기간 내 한 번 이상 푼 고유 문항 수 / 해당 교재 전체 문항 수. 반복 풀이로 진도 분자가 늘어나지 않습니다.
- 기간 정답률 = 기간 내 정답 횟수 / 전체 풀이 횟수. 반복 풀이도 포함합니다. 풀이가 없으면 정답률은 —로 표시합니다.
- 문제 풀이·시험 채점 및 이스타항공의 기존 공통 채점 경로에 기록 연결을 추가했습니다. 별도로 운영되는 오늘의 퀴즈 게이트 기록은 이 집계에 포함하지 않습니다.
- 기간을 설정하면 홈 집중학습 진도·정답률과 교재별 목표도 같은 기간을 기준으로 표시합니다. 기존 마이페이지 누적 현황은 유지됩니다.
- 「기간 해제」는 설정만 해제합니다. 풀이 기록을 삭제하지 않으며 홈은 누적 현황으로 돌아옵니다. 날짜를 바꾸면 해당 날짜 구간으로 다시 집계합니다.
- 기간·목표 설정과 이 기기 상세 이력은 계정별로 이 브라우저 또는 앱에 저장됩니다. 설정 자체는 기기 간 자동 동기화되지 않습니다.
- 서버 로그인 환경에서는 기존 user_attempts 테이블을 기간으로 조회합니다. 서버와 기기 양쪽에 있는 동일 풀이 기록은 중복 집계하지 않습니다. 다른 기기의 새 기록은 「이력 다시 불러오기」로 갱신합니다.
- 서버 날짜별 상세 이력이 없는 예전 기기 내 누적 기록은 기간별로 소급 분해하지 않습니다. 새 패치 이후의 기기 기록은 날짜와 함께 저장됩니다.
- 서버 조회 실패 시 경고를 표시하고 기기 기록만 집계합니다. 이력을 다시 불러오면 재시도합니다.

검증: 전체 코어를 Chromium에 로드하여 1440px·390px, 한국 날짜 양 끝 경계, 반복 풀이, 실제 채점 함수 연결, 홈 반영, 설정 재로딩, 잘못된 기간 거부, 기간 해제, 밝은/어두운 테마, 가로 넘침을 확인했습니다. 모의 서버에서는 1001건 페이지 조회·시간대 표현이 다른 중복 기록·계정 분리·조회 실패와 재시도를 확인했습니다. 실제 Supabase 계정과 서버 쓰기는 검증하지 않았습니다.
