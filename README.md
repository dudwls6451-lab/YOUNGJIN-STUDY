# v11.60.56 — 메뉴 접기 복구

v11.60.55에 같은 경로로 덮어쓰고 배포하세요. SQL 변경·APK 재설치가 필요 없습니다.

PC에서 메뉴 접기 시 메뉴를 완전히 숨기고 본문을 넓힙니다. 다시 클릭하면 펼칩니다. 접기 상태를 재접속 후에도 유지합니다. 모바일은 기존 서랍 메뉴 열기·닫기·배경 클릭·Escape 닫기를 유지합니다. 화면 크기가 바뀔 때 실제 표시와 aria-expanded 상태를 맞춥니다. 숨겨진 메뉴는 키보드 포커스를 받지 않습니다.

기호 제거 이후 남은 너비 강제 유지 규칙을 제거하고, 폰트에 없는 햄버거 문자 대신 CSS로 버튼 모양을 그립니다. 메뉴 항목의 기호를 되살리는 변경은 아닙니다. 기존 나눔스퀘어·집중학습·CPL·과정 분류·스터디그룹 정돈을 포함합니다.

실제 Chromium에서 PC/모바일/화면 크기 전환/상태 저장을 확인합니다. 서버 API는 모의이며 실제 Android 기기는 미검증입니다.
