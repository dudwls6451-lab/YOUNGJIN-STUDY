# v11.60.50 — 이스타항공 4회차 추가

v11.60.49 적용 사이트에 압축을 풀어 같은 경로로 덮어쓰세요. 별도 SQL이나 APK 재설치는 필요 없습니다. GitHub 배포 후 앱에서 새로고침하세요.

1~3회차와 기존 로고를 유지하고 4회차 45문항(객관식 40, 단답형 5)을 추가했습니다. 합계 180문항입니다. 학습·실전·오답·이어풀기·단답형 자가채점을 지원합니다.

첨부 파일에는 객관식 정답표가 따로 없어 제공된 선지별 분석에서 정답을 도출했습니다. 설명은 원문을 보존했으며 외부 법령/교재와 독립 대조하지 않았습니다. 4회차 44번 모범답안은 첨부 해설에서 옮겼습니다. 모든 회차 44번은 그림이 누락되어 미채점이며 각 회차 채점 가능 점수는 96점입니다. 4회차 43번도 그림은 없으나 문제에 노란 X 모양이 서술되어 있어 채점합니다. 원본 개인 채점 표시는 제외했습니다.

검증 범위는 동봉 validation 파일을 참고하세요. 실제 Supabase 및 Android 기기에서의 검증은 수행하지 않았습니다.
