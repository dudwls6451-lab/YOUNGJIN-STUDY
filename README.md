# v11.60.55 — CPL Gleim / 과정 분류 / 스터디그룹 정돈

v11.60.54 위에 같은 경로로 덮어쓰고 배포하세요. SQL 변경·APK 재설치는 필요 없습니다.

CPL Gleim 893문항을 사이트의 기존 데이터에서 그대로 포함하고 초기 로딩에 합쳤습니다. 교재를 먼저 클릭하지 않아도 과목·집중학습 선택·마이페이지 교재 목록에 나타납니다. 문항·정답·ID는 변경하지 않았습니다.

집중학습 설정을 ‘교재’와 ‘항공사 대비과정’으로 구분했습니다. 이스타항공·제주항공 복기·기존 항공사 전용 과목은 별도 과정에 속하며, 홈 진도 카드에도 분류를 표시합니다. 이스타항공을 공식 교재로 취급하지 않습니다. 기존 선택·진도는 유지합니다.

스터디그룹은 ‘내 그룹’ 가로 목록 → 그룹 정보·관리 → 조회 날짜 → 목표 → 그룹원 현황 → 게시판 순서로 재배치했습니다. PC에서 목표·현황을 넓게, 모바일에서는 한 열로 표시하고 버튼 문구가 세로로 깨지지 않게 합니다. 기존 그룹 스크립트와 서버 동작을 유지하는 레이아웃 변경입니다.

검증은 실제 Chromium에서 기존 그룹 스크립트와 모의 서버 응답으로 진행합니다. 실제 Supabase 변경·쓰기 및 실제 Android 기기 검증은 하지 않았습니다. 집중학습 선택은 계정별 로컬 저장입니다.
