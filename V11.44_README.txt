기준: v11.43

적용 파일
- index.html
- assets/app-v11-23.js
- assets/style-v11-44.css

주요 변경
1) 홈 화면
- 홈 교재별 학습률/정답률 카드는 홈에서만 표시
- 학습 허브/문제 선택/문제 풀이/마이페이지/오류 화면 진입 시 자동 숨김
- 홈 요약 영역과 마이페이지 바로가기 추가

2) 마이페이지
- 기존 '학습 통계' 메뉴를 '마이페이지'로 개편
- 전체 진도 / 누적 정답률 / 누적 풀이 / 시험 제외 요약
- ATP Gleim / 검댕이 항공법규 / 항공기상 / 항공교통통신별 학습률·정답률 카드
- 정답률이 낮은 Study Unit TOP 5 표시
- 기존 상세 교재/SU/문제별 통계는 접이식 상세 영역으로 유지

3) 문제 선택과 집중 모드
- 문제 선택 단계에서는 기존 필터와 '학습 모드 선택' Row 유지
- '시험 시작'을 누르는 순간 문제 선택 필터 전체 숨김
- 문제 풀이 카드만 집중 표시

4) 이전 문제 / 다음 문제
- 학습모드와 시험모드 모두 이전 문제 이동 지원
- 학습모드에서 이전에 답한 문제로 돌아가면 당시 선택답, 정답/오답 표시, 해설을 그대로 복원
- 보기 순서 섞기를 사용해도 같은 세션에서는 보기 순서를 유지
- 같은 문제를 뒤로 갔다 다시 봐도 학습 시도가 중복 저장되지 않음

5) 관리자 오류 보고
- 일반 사용자 오류 목록: '오류 보고' 서버 전송 방식 유지
- 관리자 '보고된 오류 총목록': '전체 복사' 버튼 추가/유지
- 전체 복사 내용: 문제 ID, 과목/SU/소단원, 보고자, 시각, 지문, 보기, 오류 메모

6) 반응형 UI
- 어두운 앱 스타일 + 청록 포인트
- iPad/넓은 화면(1024px 이상): 좌측 고정 내비게이션
- 모바일/세로 태블릿: 상단 가로 스크롤 내비게이션
- 모바일 문제 풀이: 이전/다음 버튼을 화면 하단에 고정
- 선택지 터치 영역 확대

주의

- SQL을 다시 실행할 필요 없습니다.
