# PilotBank v11.60.9 — Weekly Ranking Study Time + Pilot Grade Patch

Base: `github-question-bank-v11.60.8-unanswered-submit-confirm-one-shot-patch.zip`

## Changes
- Weekly Ranking exam time now counts toward the same per-member Supabase study-time total used by other learning modes.
- Only the active Weekly Ranking question-solving screen counts; lobby/result/comment/leaderboard browsing does not.
- Existing visibility and 10-minute idle protections remain in effect.
- Main home screen now shows a pilot-grade progress strip based on cumulative study time.
- Grade thresholds:
  - Student Pilot / 학생조종사: below 40 hours
  - Private Pilot / 자가용 조종사: 40 hours or more
  - Commercial Pilot / 사업용 조종사: 200 hours or more
  - Airline Transport Pilot / 운송용 조종사: 1,500 hours or more
- The progress bar resets for each grade band and shows remaining time to the next grade.
- At 1,500 hours and above, the strip shows the maximum grade state.
- The label intentionally says `누적 학습시간` rather than actual flight time so study activity is not presented as real-world logged flight experience.

## Database
No schema change is required. The patch reuses the existing `user_study_time_daily` storage and `add_my_study_seconds` RPC.

## Preserved from v11.60.8
- Unanswered-question submit confirmation.
- Read-only expandable question review in theory/test results and Weekly Ranking results.
- Reviewed question JSON and figures are unchanged.
